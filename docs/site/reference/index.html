Reference

Lookup tables for every block, item, recipe, tag, config option, device type, sound, screen, data component, ELCL command and message.

The reference pages are for looking things up rather than reading through. They aren't written by hand: the site generates them from the mod's own data (its registries, recipes, tags, config spec, language file and ELCL command and message tables), so they match the version shown in the footer, 1.2.1+26.3. For how things work and how to use them, start from the guide sections instead; every entry here links back to the guide pages that cover it.
