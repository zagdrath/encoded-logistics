Compute Server

encodedlogistics:compute_server · Item · Stacks to 1 · Creative tab: Encoded Logistics: Parts & Tools

A 2U rack device that gives rack.computeServerThreads (default 2) crafting threads to its network's rack Scheduler, and also runs ELCL batch jobs. With a Memory Server on the same network, in any rack, the network's racks pool into one Scheduler.

Compute Server

Shift: A 2U rack device: 2 crafting threads. With a Memory Server on the same network, in any rack, the network's racks pool into one Scheduler.

Works with

  • Server Rack
  • Memory Server
  • Fabrication Server

On a network

It counts as a device of type CMPSRV in Work with Devices and in ELCL; the first one on a network is named CMPSRV01. See Device types.
