Schematic Encoder

encodedlogistics:schematic_encoder · Item · Stacks to 64 · Creative tab: Encoded Logistics: Parts & Tools

A terminal that writes recipes onto blank Schematic Cards: a crafting recipe for a Fabricator, or a machine's inputs and outputs (items, fluids and gases) for a Gateway. Mounts like any cable part and uses one lane.

Schematic Encoder

Shift: A terminal that writes crafting and processing recipes onto Schematic Cards. Uses one lane.

Works with

  • Schematic Card
  • Encoded Schematic (Crafting)
  • Encoded Schematic (Processing)

On a network

It counts as a device of type ENCODER in Work with Devices and in ELCL; the first one on a network is named ENCODER01. See Device types.
