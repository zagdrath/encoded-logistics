Router

encodedlogistics:router · Item · Stacks to 1 · Creative tab: Encoded Logistics: Parts & Tools

A 1U rack device that moves items between separate networks, any distance apart, linked with a Link Card: up to six networks (its own included) and six routes, static or dynamic routing, and ACLs. Each Optical Transceiver in its cages adds throughput. Uses one lane.

Router

Shift: A 1U rack device: moves items between separate networks, any distance apart, 16 items/s and 16 more for each Optical Transceiver. Uses one lane.

Works with

  • Server Rack
  • Link Card
  • Optical Transceiver
  • Cross-Connect
  • Exchange Switch

On a network

It counts as a device of type ROUTER in Work with Devices and in ELCL; the first one on a network is named ROUTER01. See Device types.
