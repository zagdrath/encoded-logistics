Block of Gallium

encodedlogistics:gallium_block · Block · Stacks to 64 · Creative tab: Encoded Logistics: Materials

Block of Gallium: a storage block of nine ingots, crafted back into nine. It works as a beacon base.

How to get it

Used to make

  • Gallium Ingot

As a block

Hardness5
Blast resistance6
Tooliron pickaxe (needed for it to drop)
Light level0 in its default state
