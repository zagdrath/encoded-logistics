Collector Plane

encodedlogistics:collector_plane · Item · Stacks to 64 · Creative tab: Encoded Logistics: Parts & Tools

A cable part that breaks the block in front of it (as an iron pickaxe would) and vacuums up dropped items into the network. A Filter or Fuzzy Match Module limits what it takes. Planes side by side join up. Uses one lane.

Collector Plane

Uses 1 lane

Shift: Breaks the block in front (as an iron pickaxe) and collects dropped items into the network. Joins neighbouring planes. Uses one lane.

Works with

  • Filter Module
  • Fuzzy Match Module
  • Deployer Plane

On a network

It counts as a device of type COLLECTOR in Work with Devices and in ELCL; the first one on a network is named COLLECTOR01. See Device types.
