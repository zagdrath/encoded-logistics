Programmable Logic Controller

encodedlogistics:plc · Block · Stacks to 64 · Creative tab: Encoded Logistics

A Programmable Logic Controller: it runs one ELCL program over and over, like a PLC scan, reading and driving redstone on each face, with four slots for sensor modules. It runs on its own FE, or on its network when cabled to one. Right-click for its screens.

Programmable Logic Controller

Shift: A Programmable Logic Controller: runs one ELCL program over and over, like a PLC scan. Each face reads and drives redstone. Four slots for sensor modules. Runs on FE, or on its network when cabled to one. Right-click for its screens.

Works with

  • Presence Sensor
  • Inventory Sensor
  • Fluid Sensor
  • Light Sensor
  • Timer Module
  • EEPROM Cartridge

On a network

It counts as a device of type PLC in Work with Devices and in ELCL; the first one on a network is named PLC01. See Device types.

How to get it

Used to make

Nothing.

As a block

Hardness2
Blast resistance6
Toolany pickaxe (needed for it to drop)
Light level0 in its default state
