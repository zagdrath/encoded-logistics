Access Point

encodedlogistics:access_point · Block · Stacks to 64 · Creative tab: Encoded Logistics

The radio for its network's Wireless Controller. Mount it on a cable or network block (it connects only on the side it's mounted on); each one online lets the controller serve rack.wirelessApClients (default 8) more Wireless Bridges and Ports. Uses one lane.

Access Point

Shift: The radio for its network's Wireless Controller. Mount it on a cable (or any network block); each one online lets the controller serve 8 Wireless Bridges and Ports.

Works with

  • Wireless Controller
  • Wireless Bridge
  • Wireless Ingress Port
  • Wireless Egress Port
  • Small Wireless Bridge

On a network

It counts as a device of type AP in Work with Devices and in ELCL; the first one on a network is named AP01. See Device types.

How to get it

Used to make

Nothing.

As a block

Hardness3
Blast resistance6
Toolany pickaxe (needed for it to drop)
Light level0 in its default state
