Handheld Terminal

encodedlogistics:handheld_terminal · Item · Stacks to 1 · Creative tab: Encoded Logistics: Parts & Tools

An Access Terminal you carry. Link it by using it on a Relay Antenna or Network Controller (it then works in an antenna's range), or on a Wireless Controller (it then works anywhere). It runs on its own FE battery: charge it in any FE charger or held against a Capacitor Bank.
