Exchange Switch

encodedlogistics:exchange_switch · Block · Stacks to 64 · Creative tab: Encoded Logistics

An Internet Exchange, two blocks tall: Routers on any networks join it with a Cross-Connect and peer there, through its route server or with each other. Its owner can require approval for members. Keeps its chunk loaded while it has members. Uses one lane.

Exchange Switch

Shift: An Internet Exchange, two blocks tall: Routers on any networks join it with a Cross-Connect and peer there, through its route server or with each other. Uses one lane; its owner approves members. Keeps its chunk loaded while it has members.

Works with

  • Cross-Connect
  • Router

On a network

It counts as a device of type XSW in Work with Devices and in ELCL; the first one on a network is named XSW01. See Device types.

How to get it

Used to make

Nothing.

As a block

Hardness3
Blast resistance6
Toolany pickaxe (needed for it to drop)
Light level0 in its default state

  • Screens (Terminal OS and ELCL)
