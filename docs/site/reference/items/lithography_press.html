Lithography Press

encodedlogistics:lithography_press · Block · Stacks to 64 · Creative tab: Encoded Logistics

Etches dies from Silicon Wafers or Doped Silicon with a photomask, which it never uses up. It runs on FE from any face and needs no network, so it's the first machine you build.

Lithography Press

Shift: Etches dies from silicon wafers with a reusable photomask. Runs on FE; no network needed.

Works with

  • Logic Photomask
  • Memory Photomask
  • Processor Photomask
  • Storage Photomask
  • Silicon Wafer
  • Doped Silicon

How to get it

Used to make

Nothing.

As a block

Hardness3
Blast resistance6
Toolany pickaxe (needed for it to drop)
Light level0 in its default state
