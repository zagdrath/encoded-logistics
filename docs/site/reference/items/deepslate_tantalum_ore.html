Deepslate Tantalum Ore

encodedlogistics:deepslate_tantalum_ore · Block · Stacks to 64 · Creative tab: Encoded Logistics: Materials

Tantalum ore in deepslate, found deep in the Overworld. Mine it with an iron pickaxe for Raw Tantalum.

How to get it

Mining it drops Raw Tantalum (Silk Touch drops the block itself).

Generates in the Overworld (4 veins per chunk, evenly from the bottom to Y -8).

Used to make

  • Tantalum Dust
  • Tantalum Ingot

As a block

Hardness4.5
Blast resistance3
Tooliron pickaxe (needed for it to drop)
Light level0 in its default state
