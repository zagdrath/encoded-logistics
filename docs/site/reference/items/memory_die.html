Memory Die

encodedlogistics:memory_die · Item · Stacks to 64 · Creative tab: Encoded Logistics: Materials

The second-tier chip, etched from Doped Silicon and Ferrite with the Memory Photomask. It goes into the 128K and 512K Storage Dies, the Fabrication and Schematic Terminals, Job Buffers, Gateways, Link Cards and much of the rack gear.
