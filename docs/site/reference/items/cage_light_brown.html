Brown Cage Light

encodedlogistics:cage_light_brown · Block · Stacks to 64 · Creative tab: Encoded Logistics

Brown Cage Light: a caged lamp that mounts on any face, lit by redstone (or inverted, always on, or by its network with CHGLGT), at a light level you set. On a network it is also a device ELCL can switch.

Works with

  • Control Interface
  • Programmable Logic Controller

On a network

It counts as a device of type LGT in Work with Devices and in ELCL; the first one on a network is named LGT01. See Device types.

How to get it

Used to make

Nothing.

As a block

Hardness1
Blast resistance6
Toolany pickaxe
Light level0 in its default state
