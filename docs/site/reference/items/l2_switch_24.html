24-Port L2 Switch

encodedlogistics:l2_switch_24 · Item · Stacks to 1 · Creative tab: Encoded Logistics: Parts & Tools

A 1U rack device: a pool of rack.l2Switch24Lanes (default 24) rack-local lanes for the other devices in its rack, which then take no network lanes; it uses one. Pooled devices can serve other segments.

24-Port L2 Switch

Shift: A 1U rack device: 16 rack-local lanes for the other devices in its rack, which then take no network lanes; it uses one.

Works with

  • Server Rack
  • Link Card

On a network

It counts as a device of type SWITCH in Work with Devices and in ELCL; the first one on a network is named SWITCH01. See Device types.

How to get it

Used to make

  • Interconnect Module
