DSPNBR

Command line only Firewall: None

Display Neighbours

Syntax

DSPNBR RTR(device name)

The first parameter can be given without its keyword, in that order: RTR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTRRouterDevice name
prompter field 10 long; F4 lists devices		Yes

DSPNBR opens Display Neighbours for a Router: the Routers it exchanges routes with, those on networks it links to, that link to it, or that it peers with at an Exchange Switch. Each row shows how the neighbour is reached, its state, the hop's cost, any cost override, and how long it has been up. The top line counts the neighbours up and down. You type it at a command line; it doesn't run in a program.

StateMeaning
*INITComing up.
*FULLIn sync: routes are being exchanged.
*DOWNIt missed its hellos. Its cost shows -.

The override is what CHGNBR (or the Router's Table tab) set; - for none. A Router in *STATIC mode has no neighbours, and the screen says so. It refreshes every two seconds; PageUp / PageDown roll it, F10 switches to the route table (DSPROUTE), and Enter goes back.

RTR is the Router's device name (F4 lists the devices); a name that isn't a Router on your network shows ELC2601. In a program, RTVNBRSTS reads a neighbour's state. See Routers and Screens.
