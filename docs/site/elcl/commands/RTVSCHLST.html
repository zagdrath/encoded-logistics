RTVSCHLST

Command line and programs Firewall: VIEW

Retrieve Schematic List

Syntax

RTVSCHLST RTNLIST(*LIST variable) [HOLDER(*ALL | name (up to 10 characters))] [RTNCOUNT(*INT variable)]

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTNLISTReturn listA *LIST variable the command setsYes
HOLDERHolderName (up to 10 characters)
prompter field 10 long		No*ALL*ALL
RTNCOUNTReturn countA *INT variable the command setsNo

Lists what the network can craft: every output of the schematics in its schematic holders (Fabrication Servers, Fabricators, Gateways, a Midrange System and the others Work with Schematics lists), each ID once, into RTNLIST, and how many there are into RTNCOUNT. Items come back as STRCRAFT takes them (IRON_INGOT, encodedlogistics:logic_die); a fluid or gas output comes back as its type and ID, FLUID minecraft:water or PRES arcforge:hydrogen.

HOLDER(*ALL) (the default) looks at every holder. A name looks only at holders whose device name is that name, or whose shown name starts with it (FABSRV01, FAB). No holder matching a name is ELC2501; a network with no holders at all gives an empty list with *ALL. The command sends no completion message. See Schematics.

DCL VAR(&MAKES) TYPE(*LIST)
DCL VAR(&N) TYPE(*INT)
RTVSCHLST HOLDER(FABSRV01) RTNLIST(&MAKES) RTNCOUNT(&N)
SNDPGMMSG MSG('FABSRV01 holds schematics for' *BCAT %CHAR(&N) *BCAT 'outputs')
