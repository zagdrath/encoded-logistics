RTVRTE

Command line and programs Firewall: VIEW

Retrieve Route

Syntax

RTVRTE RTR(device name) NETWORK(name (up to 10 characters)) [RTNNEXT(*CHAR variable)] [RTNCOST(*INT variable)] [RTNHOPS(*INT variable)]

The first 2 parameters can be given without their keyword, in that order: RTR, NETWORK.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTRRouterDevice name
prompter field 10 long; F4 lists devices		Yes
NETWORKNetworkName (up to 10 characters)
prompter field 10 long		Yes
RTNNEXTReturn next hopA *CHAR variable the command setsNo
RTNCOSTReturn costA *INT variable the command setsNo
RTNHOPSReturn hopsA *INT variable the command setsNo

Looks a network up in a Router's route table, the table DSPROUTE shows. RTR is the Router's device name (ROUTER01); a name that isn't a Router on your network is ELC2601. NETWORK is the destination's system name, its SYSNAME (ELNET02), as the route table lists it.

The table holds the networks the Router links to itself and, for a Router in Dynamic mode, every network it has learned a path to from its neighbours. A Router in Static mode knows only its own links.

VariableGets
RTNNEXTWhere the path goes first: DIRECT for a network the Router links to or one hop away, IX:NAME through an Exchange Switch, or the name of the next network on the way
RTNCOSTThe path's cost: lower is better. Each hop costs more the less it carries (see rack.routingBaseCost)
RTNHOPSHops to get there (1 for a direct link)

A network that isn't in the table (not linked, not learned, or unreachable now) is ELC2602. The command sends no completion message. See Routers.

DCL VAR(&NEXT) TYPE(*CHAR) LEN(24)
DCL VAR(&HOPS) TYPE(*INT)
RTVRTE RTR(ROUTER01) NETWORK(ELNET04) RTNNEXT(&NEXT) RTNHOPS(&HOPS)
MONMSG MSGID(ELC2602) EXEC(DO)
  SNDMSG MSG('No route to ELNET04') TOUSR(*SYSOPR)
  RETURN
ENDDO
SNDPGMMSG MSG('ELNET04 via' *BCAT &NEXT *BCAT 'in' *BCAT %CHAR(&HOPS) *BCAT 'hops')
