APVIXMBR

Command line and programs Firewall: BUILD

Approve Exchange Member

Syntax

APVIXMBR IX(name (up to 10 characters)) NETWORK(name (up to 10 characters))

The first 2 parameters can be given without their keyword, in that order: IX, NETWORK.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
IXExchangeName (up to 10 characters)
prompter field 10 long		Yes
NETWORKNetworkName (up to 10 characters)
prompter field 10 long		Yes

Approves a network's request to join an Exchange Switch, as WRKIX's 8=Approve does. Only the exchange's owner can approve: the player who placed it, or (at a terminal) a server operator; in a batch job, the job's user has to be the owner. Anyone else gets ELC2612, which names the owner. The command also needs the Firewall's build permission on your own network, like every command that changes something. See Exchange Switch and Directory Server.

  • IX: the exchange, by its device name on your network (XSW01) or by the exchange's own name, which finds it wherever it is. ELC2610 when neither matches.
  • NETWORK: the requesting network's system name, as WRKIX lists it. A network that has neither asked nor joined is ELC2611.

When there's no request from that network (it's already a member), or the exchange has no free port for it, the command fails with ELC2613. On success the network gets a port and the command sends ELC2614.

APVIXMBR IX(XSW01) NETWORK(ELNET07)
MONMSG MSGID(ELC2613) EXEC(SNDPGMMSG MSG('No free port, or no request'))
