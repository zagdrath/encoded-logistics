WRKIX

Command line only Firewall: None

Work with Exchange

Syntax

WRKIX IX(name (up to 10 characters))

The first parameter can be given without its keyword, in that order: IX.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
IXExchangeName (up to 10 characters)
prompter field 10 long		Yes

WRKIX opens Work with Exchange on an Exchange Switch: its members, the Routers that joined it with a Cross-Connect, with each one's port, whether it's up, how it peers (*RS through the route server, *BILAT with chosen peers), the routes it learns through the exchange and its traffic. Join requests waiting for the owner show *REQUEST. The top line names the exchange, its owner, its members and ports, and how it takes members. You type it at a command line; it doesn't run in a program.

IX is the exchange's name, or its device name on your network. One that isn't found is ELC2610.

OptionWhat it does
4=RemoveRemoves the member (RMVIXMBR), after you confirm.
5=DisplayThe member's details.
8=ApproveApproves a join request (APVIXMBR).

Removing and approving are the exchange owner's (ELC2612 for anyone else). F10 shows the peering sessions instead, F11 only the join requests; the same key again goes back. See Exchange Switch and Directory Server and Screens.
