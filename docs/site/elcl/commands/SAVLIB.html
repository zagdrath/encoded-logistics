SAVLIB

Command line and programs Firewall: None

Save Library

Syntax

SAVLIB LIB(name (up to 10 characters)) DEV(device name)

The first 2 parameters can be given without their keyword, in that order: LIB, DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LIBLibraryName (up to 10 characters)
prompter field 10 long; F4 lists libraries		Yes
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes

SAVLIB writes a whole library onto an 8" Diskette: its source members (with their types, texts, sequence numbers and change dates), its programs, and its database files with their records. The diskette is an item, so you can carry the library to another network, keep it as a backup, or hand it to another player, and bring it back with RSTLIB.

DEV is the diskette drive, by device name:

DriveDiskettesSAVLIB writes to
Midrange System (MIDRANGE01...)Its diskette slot, and a second with an Expansion CabinetThe diskette in its default drive, else the first one in it
Integrated Midrange SystemEvery diskette in the Diskette Magazine in itThe same: its default drive's diskette first
Card Reader (CARDRDR01...)OneThat one

A Midrange System's drives are online only while it's running. No device of that name is ELC1301, an offline one ELC1302, a drive with no diskette ELC1310. The device is checked first, so these come before any problem with the library (ELC0201 when there's no such library).

What fits#

A diskette holds elcl.disketteBytes (default 65,536) bytes, and can hold several libraries. A library of the same name already on it is replaced, so its space counts as free. What a library takes: each member's characters plus one a line, each program's saved source counted the same way again, and each file's records. A library that won't fit in what's free is ELC1311, which gives both numbers; nothing is written.

Anyone may save any library, ELSYS included (its system files aren't saved: they're the network's own data). Done: ELC0220, naming the device and the diskette's label.

SAVLIB LIB(ZAGLIB) DEV(MIDRANGE01)

See Saving to diskette and The Midrange line.

System values, save and restore

WRKSYSVAL RTVSYSVAL CHGSYSVAL RSTLIB
