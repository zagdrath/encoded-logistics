DLTMBR

Command line and programs Firewall: None

Delete Member

Syntax

DLTMBR MBR(library/name)

The first parameter can be given without its keyword, in that order: MBR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MBRMemberLibrary/name
prompter field 21 long; F4 lists members		Yes

DLTMBR deletes a source member from a library. There's no confirmation on the command line (Work with Members option 4 asks first).

  • The library must be one you may change: ELSYS is ELC0205, someone else's *USE library ELC0401.
  • A member someone else has open in the editor can't be deleted: ELC0208.
  • No member of that name is ELC0202.

Only the source goes. A program compiled from it stays and still runs (it keeps its own copy of the source); delete it with DLTPGM. With folder sync on, the member's file moves to the .deleted folder beside it. Done: ELC0217.

DLTMBR MBR(ZAGLIB/RESTOCKOLD)

Libraries, members and programs
