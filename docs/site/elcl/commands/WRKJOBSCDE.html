WRKJOBSCDE

Command line only Firewall: None

Work with Job Schedule Entries

Syntax

WRKJOBSCDE

It takes no parameters.

Work with Job Schedule Entries lists the system's job schedule entries: name, status (*SCD scheduled or *HLD held), frequency (*ONCE, *DAILY or *INTERVAL), the next run (game day and time) and the command. It's also option 11 on the main menu. Type an option next to an entry:

OptionWhat it does
2Change it: ADDJOBSCDE's prompter with its values. Enter removes the entry and adds it again as you changed it, so it comes back scheduled (*SCD), with its next run worked out afresh.
3Hold it (HLDJOBSCDE); on a held entry, release it (RLSJOBSCDE).
4Remove it, after you confirm (RMVJOBSCDE).
10Submit now: runs its command as a batch job straight away (SBMJOB). The entry and its timetable stay as they were.

F6 prompts ADDJOBSCDE to add an entry. Hold and release send no message: the status column shows the change.
