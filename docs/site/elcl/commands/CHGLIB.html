CHGLIB

Command line and programs Firewall: None

Change Library

Syntax

CHGLIB LIB(name (up to 10 characters)) [TEXT(*SAME | text)] [AUT(*SAME | *USE | *CHANGE)]

The first parameter can be given without its keyword, in that order: LIB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LIBLibraryName (up to 10 characters)
prompter field 10 long; F4 lists libraries		Yes
TEXTText 'description'Text
prompter field 50 long		No*SAME*SAME
AUTPublic authoritySpecial valueNo*SAME*SAME, *USE, *CHANGE

CHGLIB changes a library's text, its public authority, or both. Leave a parameter at *SAME to keep it as it is.

  • AUT(*USE): anyone can read the library and call its programs, but only its owner and a security officer can change what's in it. AUT(*CHANGE): anyone can also create, edit, copy into, rename, delete and compile members in it.
  • Who may run it: the library's owner, a security officer, or anyone at all for a library the system owns (QSYS): ELGPL, and the libraries folder sync makes from new folders. Anyone else gets ELC0401 (naming *OWNER).
  • ELSYS can't be changed: ELC0205.

Done: ELC0212. Work with Libraries option 2 runs this command from a window.

CHGLIB LIB(ZAGLIB) AUT(*CHANGE)
CHGLIB LIB(ZAGLIB) TEXT('Shared with the base crew')

See Libraries and the editor.
