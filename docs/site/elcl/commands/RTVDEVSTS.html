RTVDEVSTS

Command line and programs Firewall: VIEW

Retrieve Device Status

Syntax

RTVDEVSTS DEV(device name) [RTNSTS(*CHAR variable)] [RTNTYPE(*CHAR variable)]

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes
RTNSTSReturn statusA *CHAR variable the command setsNo
RTNTYPEReturn device typeA *CHAR variable the command setsNo

Looks a device up by its name and returns its status and type.

Device names#

Every device that takes part in ELCL has a name: its type and a number, given the first time it's on a network (the lowest number free there) and kept with the device until someone renames it with RNMDEV or Work with Devices' 2=Change. Examples: CTLIF01 (Control Interface), ELDESK01 (Terminal Desk), UPS01, TAPELIB01, EGRESS01, PLC01, ARCCRU01 (an Arc Crusher with a Small Wireless Bridge). Device types lists every type, and WRKDEV shows the names on your network. Names aren't case-sensitive. A name with a slash, ELNET02/UPS01, is a device another network publishes through its Directory Servers (see RTVDIRENT); your Firewall permission on that network decides whether you may use it.

Returns#

VariableGets
RTNSTS*DISABLED for a cable part switched off with CHGDEVSTS, *FAULT for a rack device in a fault state, otherwise *ONLINE or *OFFLINE
RTNTYPEThe device's type code, the start of its name: UPS, TAPELIB, EGRESS... (DESK for a Terminal Desk, whose names start ELDESK)

A name no device on the network has is ELC1301: the command has no "not found" status, so monitor for it. It sends no completion message.

DCL VAR(&STS) TYPE(*CHAR) LEN(10)
DCL VAR(&TYPE) TYPE(*CHAR) LEN(10)
RTVDEVSTS DEV(UPS01) RTNSTS(&STS) RTNTYPE(&TYPE)
MONMSG MSGID(ELC1301) EXEC(CHGVAR VAR(&STS) VALUE('*MISSING'))
IF COND(&STS *NE '*ONLINE') THEN(SNDMSG MSG('UPS01 is' *BCAT &STS) TOUSR(*SYSOPR))
