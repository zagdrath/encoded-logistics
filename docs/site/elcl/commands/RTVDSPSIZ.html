RTVDSPSIZ

Command line and programs Firewall: None

Retrieve Display Size

Syntax

RTVDSPSIZ DEV(device name) [RTNW(*INT variable)] [RTNH(*INT variable)] [RTNPXW(*INT variable)] [RTNPXH(*INT variable)]

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes
RTNWReturn width (panels)A *INT variable the command setsNo
RTNHReturn height (panels)A *INT variable the command setsNo
RTNPXWReturn width (canvas px)A *INT variable the command setsNo
RTNPXHReturn height (canvas px)A *INT variable the command setsNo

RTVDSPSIZ tells a program how big a Display Panel screen is, so it can lay out regions and text that fit whatever screen it's given. Each panel is 32 x 32 canvas pixels.

VariableReceives
RTNWThe screen's width in panels (1 to rack.displayMaxWidth)
RTNHIts height in panels (1 to rack.displayMaxHeight)
RTNPXWIts width in canvas pixels: RTNW x 32
RTNPXHIts height in canvas pixels: RTNH x 32

Declare them *INT, and give only the ones you need. The screen doesn't have to be online. A DEV that isn't on the network is ELC1301, and a device that isn't a Display Panel screen ELC1303. It sends no completion message.

Region positions and sizes (CHGDSPRGN) are in canvas pixels. How much text fits at each size is on SNDDSPTXT.

DCL VAR(&W) TYPE(*INT)
DCL VAR(&H) TYPE(*INT)
DCL VAR(&HALF) TYPE(*INT)
RTVDSPSIZ DEV(DSP01) RTNPXW(&W) RTNPXH(&H)
CHGVAR VAR(&HALF) VALUE(&W / 2)
CHGDSPRGN DEV(DSP01) RGN(A) W(&HALF)              /* left half  */
CHGDSPRGN DEV(DSP01) RGN(B) X(&HALF)              /* right half */
SNDDSPGPH DEV(DSP01) RGN(A) STAT(*ENERGY)
SNDDSPWDG DEV(DSP01) RGN(B) WDG(*UPS)

Messages, displays and output

SNDMSG DSPMSG SNDDSPTXT CLRDSP CHGDSPRGN SNDDSPWDG SNDDSPGPH SNDDSPIMG PRTTXT PRTRPT
