CHGMCHCFG

Command line and programs Firewall: BUILD

Change Machine Configuration

Syntax

CHGMCHCFG MCH(device name) [RSMODE(*SAME | *IGNORE | *HIGH | *LOW | *PULSE | *THROTTLE)] [SIDE(*SAME | *TOP | *BOTTOM | *LEFT | *RIGHT | *BACK | *FRONT)] [SIDEMODE(*SAME | name (up to 10 characters))] [AUTOEJECT(*SAME | *YES | *NO)] [PWRNET(*SAME | *YES | *NO)] [GATEWAY(*SAME | *NONE | device name)]

The first parameter can be given without its keyword, in that order: MCH.

Changes an Arcforge machine's settings, as its own screen (or Work with Machines' 2=Change, which runs this command) would. Every parameter left at *SAME stays as it is. MCH names the machine as for RTVMCHSTS (ELC1301, ELC1318); a machine that's gone or not loaded is ELC1302. See Arcforge.

ParameterSets
RSMODEThe redstone mode, from the ones the machine's Redstone tab offers: *IGNORE, *HIGH, *LOW, *PULSE, *THROTTLE
SIDE with SIDEMODEOne side's mode, the side counted from the machine's front (*TOP, *BOTTOM, *LEFT, *RIGHT, *BACK, *FRONT), the mode by the name the machine's screen uses (input, output, energy, none...). Give both or neither: one alone is ELC0102. A machine with no side settings is ELC1320
AUTOEJECTWhether it pushes its output out by itself
PWRNETWhether the network's energy powers it, through its bridge (*YES for a machine without FE is ELC1320)
GATEWAYThe Gateway whose crafting steps it runs, by device name; *NONE unlinks it. A device that isn't a Gateway is ELC1303

The settings go through the machine's own rules: one it doesn't have is ELC1320, a value it refuses (or can't take now) is ELC1321, and a multiblock that isn't formed is ELC1319. They're applied in the order of the table, and the command stops at the first one refused, so the ones before it are changed.

On success it sends ELC1322, also when everything was *SAME.

CHGMCHCFG MCH(ARCCRU01) RSMODE(*IGNORE) AUTOEJECT(*YES)
CHGMCHCFG MCH(ARCCRU01) GATEWAY(GATEWAY01) PWRNET(*YES)
CHGMCHCFG MCH(ELECTR01) SIDE(*BACK) SIDEMODE(input)

Machines (Arcforge)
