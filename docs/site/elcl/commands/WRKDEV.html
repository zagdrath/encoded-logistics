WRKDEV

Command line only Firewall: None

Work with Devices

Syntax

WRKDEV

It takes no parameters.

WRKDEV opens Work with Devices on your terminal: every device on the network, with its type, name, location, the lanes it uses and its status (Online, Offline dim, a fault or what it's busy with bright). It's Main Menu option 3. Like every screen command, you type it at a command line; it doesn't run in a program.

The Device column starts with the name scripts use for it (CTLIF01, UPS01...), given when the device first joins a network (its type and the lowest number free) and kept with the device until it's renamed. A rack's devices are listed under the rack's location.

OptionWhat it does
2=ChangeA window to rename the device; it runs RNMDEV with the new name.
5=DisplayThe device's details: type, name, where it is, lanes and status.
8=LocatePicks the device out in the world for ten seconds.

In a program, RTVDEVLST and RTVDEVSTS give the same information, and the system file ELSYS/DEVICES holds it as records (DSPPFM, RUNQRY). The screen needs the Firewall's view permission. See Screens.
