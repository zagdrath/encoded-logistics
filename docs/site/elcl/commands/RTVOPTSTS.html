RTVOPTSTS

Command line and programs Firewall: VIEW

Retrieve Optical Status

Syntax

RTVOPTSTS DEV(device name) [SPAN(*FIRST | text)] [CHANNEL(*ALL | whole number)] [RTNLANES(*INT variable)] [RTNLOSS(*INT variable)] [RTNQUAL(*INT variable)] [RTNPROT(*CHAR variable)]

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes
SPANSpanText
prompter field 24 long		No*FIRST*FIRST
CHANNELChannelWhole number
1 to 40		No*ALL*ALL
RTNLANESReturn lanesA *INT variable the command setsNo
RTNLOSSReturn lanes lostA *INT variable the command setsNo
RTNQUALReturn quality (%)A *INT variable the command setsNo
RTNPROTReturn protectionA *CHAR variable the command setsNo

Reports on an optical span: the fiber run between two optical devices, as DSPOPT shows it. DEV is an Optical Multiplexer (block or rack), an Optical Amplifier (block or rack) or an Optical Transport Shelf, by its device name; anything else is ELC2701. See Optical networking.

Picking the span#

  • A multiplexer has one span, named after both ends: MUX01-MUX02 (MUX01-? before it's paired).
  • A Transport Shelf's span is named the same way (OTS01-OTS02) and has a working path and, with a Protection Card, a protect path.
  • An amplifier's span is its own name: the figures are the amplifier's (full lanes, 100% quality while it's on).

SPAN(*FIRST) (the default) takes the active span (on a shelf, the path in use). A name takes that span, preferring the active path when both a shelf's paths have it. A name the device doesn't have is ELC2703.

CHANNEL(n) (1 to 40) makes RTNLANES that channel's lanes instead of the whole span's. A channel with no network on it is ELC2704.

Returns#

VariableGets
RTNLANESLanes the span (or the channel) delivers; 0 while it's down
RTNLOSSLanes lost to span length (see optical.fiberSpanThreshold); 0 while it's down
RTNQUALSignal quality, 0 to 100; 0 while it's down
RTNPROTThe path's protection state: *ACTIVE, *STANDBY, *FAILED, or *NONE without protection

The command sends no completion message.

DCL VAR(&QUAL) TYPE(*INT)
DCL VAR(&PROT) TYPE(*CHAR) LEN(8)
RTVOPTSTS DEV(OTS01) RTNQUAL(&QUAL) RTNPROT(&PROT)
IF COND(&QUAL *LT 80) THEN(SNDMSG MSG('OTS01 span quality' *BCAT %CHAR(&QUAL) *TCAT '%') TOUSR(*SYSOPR))
