WRKHW

Command line only Firewall: None

Work with Hardware

Syntax

WRKHW [DEV(*ALL | device name)]

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		No*ALL*ALL

WRKHW opens Work with Hardware: every chassis on the network (Chassis Switches, Blade Enclosures, Optical Transport Shelfs), a row for each bay with a part in it (or a failed one): the chassis, the slot, the part (cards, blades, power supplies, modules), its status and a detail. The top line counts the network's chassis, cards and faults. You type it at a command line; it doesn't run in a program.

  • DEV(*ALL), the default, shows every chassis. Name one (its device name) to see only its bays; a name that isn't a chassis on the network shows no rows.
  • F11 shows every bay, the empty ones too; F11 again goes back.
OptionWhat it does
5=DisplayThe part's details, as its popup in the world shows them.
8=LocateOutlines the part's faceplate in the world for ten seconds; its coordinates show on the message line.

See Modular chassis and Screens.
