SUBR

Programs only Firewall: None Runs on a PLC with no network

Subroutine

Syntax

SUBR SUBR(name (up to 10 characters))

The first parameter can be given without its keyword, in that order: SUBR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
SUBRSubroutineName (up to 10 characters)
prompter field 10 long		Yes

SUBR starts a subroutine: a named block of statements, closed by ENDSUBR, that the program runs with CALLSUBR from anywhere and comes back from. Use one for anything you would otherwise write out twice.

  • Subroutines go after the main body, before ENDPGM, one after another. Once the first SUBR has come, only more subroutines may follow: any other statement there is ELC0001. End the main body with RETURN; if it runs on into the first SUBR, the program ends there.
  • A SUBR inside a block (a loop, a DO group, a SELECT or another subroutine) is ELC0009.
  • The name is up to 10 characters. Two subroutines with the same name are ELC0103.
  • A subroutine has no parameters or variables of its own: it uses the program's variables, so set the ones it works on before the CALLSUBR. It can give back one whole number through ENDSUBR RTNVAL().
  • Labels inside a subroutine can't be reached by a GOTO from outside it (ELC0014), and a LEAVE or ITERATE in it can't act on a loop of the main body.
  • A program-level MONMSG covers the subroutines' commands too.

More on subroutines.

PGM
  DCL VAR(&ITEM) TYPE(*CHAR) LEN(64)
  DCL VAR(&MIN)  TYPE(*INT)
  DCL VAR(&N)    TYPE(*INT)

  CHGVAR VAR(&ITEM) VALUE('minecraft:iron_ingot')
  CHGVAR VAR(&MIN) VALUE(512)
  CALLSUBR SUBR(TOPUP)
  CHGVAR VAR(&ITEM) VALUE('minecraft:copper_ingot')
  CHGVAR VAR(&MIN) VALUE(256)
  CALLSUBR SUBR(TOPUP)
  RETURN

  SUBR SUBR(TOPUP)
    RTVITMCNT ITEM(&ITEM) RTNCOUNT(&N) NOTFND(*ZERO)
    IF COND(&N *LT &MIN) THEN(STRCRAFT ITEM(&ITEM) QTY(&MIN - &N))
    MONMSG MSGID(ELC1400)
  ENDSUBR
ENDPGM
