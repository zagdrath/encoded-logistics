CALLSUBR

Programs only Firewall: None Runs on a PLC with no network

Call Subroutine

Syntax

CALLSUBR SUBR(name (up to 10 characters)) [RTNVAL(*INT variable)]

The first 2 parameters can be given without their keyword, in that order: SUBR, RTNVAL.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
SUBRSubroutineName (up to 10 characters)
prompter field 10 long		Yes
RTNVALReturn valueA *INT variable the command setsNo

CALLSUBR runs a subroutine of the same program and, when the subroutine reaches its ENDSUBR, carries on with the statement after the CALLSUBR. To run another program instead, use CALL.

  • SUBR names a SUBR in this program; one that doesn't exist is ELC0010. A subroutine may be anywhere among the subroutines, before or after the one calling it.
  • RTNVAL names an *INT variable (exactly *INT: a *DEC is ELC0103) that receives the subroutine's ENDSUBR RTNVAL() value. Leave it out if you don't need the value.
  • The subroutine shares the program's variables, so set whatever it works on before calling it, and read what it changed afterwards.
  • Subroutines can call each other, and themselves, up to 16 deep in one program; a 17th is ELC0011, an escape message like any other.
PGM
  DCL VAR(&DEVS) TYPE(*LIST)
  DCL VAR(&DEV)  TYPE(*CHAR) LEN(10)
  DCL VAR(&STS)  TYPE(*CHAR) LEN(10)
  DCL VAR(&BAD)  TYPE(*INT)
  DCL VAR(&RC)   TYPE(*INT)

  RTVDEVLST TYPE(*ALL) RTNLST(&DEVS)
  FOREACH VAR(&DEV) IN(&DEVS)
    CALLSUBR SUBR(CHECK) RTNVAL(&RC)
    CHGVAR VAR(&BAD) VALUE(&BAD + &RC)
  ENDFOR
  SNDPGMMSG MSG(%CHAR(&BAD) *BCAT 'devices not online')
  RETURN

  SUBR SUBR(CHECK)
    RTVDEVSTS DEV(&DEV) RTNSTS(&STS)
    IF COND(&STS *EQ '*ONLINE') THEN(CHGVAR VAR(&RC) VALUE(0))
    ELSE CMD(CHGVAR VAR(&RC) VALUE(1))
  ENDSUBR RTNVAL(&RC)
ENDPGM
