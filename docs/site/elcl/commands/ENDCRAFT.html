ENDCRAFT

Command line and programs Firewall: CRAFT

End Crafting

Syntax

ENDCRAFT CRFJOB(name (up to 10 characters))

The first parameter can be given without its keyword, in that order: CRFJOB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
CRFJOBCraft jobName (up to 10 characters)
prompter field 10 long		Yes

Cancels a crafting job that's still on a Scheduler, as Work with Crafting Jobs' 4=Cancel does. Everything the job holds (the ingredients it took and what it has made so far) goes back into the network's storage, and the job goes into the crafting history as *CANCELLED.

CRFJOB takes the job's ID (C0042) or its number (42). A job that has already ended, a number no job has, or an ID that isn't a number is ELC1404. The command sends no completion message: check with RTVCRFSTS if you need to.

DCL VAR(&JOB) TYPE(*CHAR) LEN(10)
DCL VAR(&STALL) TYPE(*CHAR) LEN(12)
DCL VAR(&STEPS) TYPE(*LIST)
STRCRAFT ITEM(PISTON) QTY(64) RTNCRFJOB(&JOB)
DLYJOB DLY(600)
RTVCRFSTP JOB(&JOB) RTNLIST(&STEPS) RTNSTALL(&STALL)
MONMSG MSGID(ELC2502) EXEC(RETURN)
IF COND(&STALL *EQ '*NOMACHINE') THEN(ENDCRAFT CRFJOB(&JOB))

Crafting

STRCRAFT RTVCRFSTS RTVCRFLOG RTVSCHLST RTVCRFSTP
