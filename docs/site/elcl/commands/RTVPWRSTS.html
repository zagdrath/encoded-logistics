RTVPWRSTS

Command line and programs Firewall: VIEW

Retrieve Power Status

Syntax

RTVPWRSTS [RTNSRC(*CHAR variable)] [RTNCHG(*DEC variable)] [RTNLOAD(*INT variable)] [RTNSTORED(*INT variable)] [RTNCAP(*INT variable)] [RTNDRVSTO(*INT variable)] [RTNDRVCAP(*INT variable)]

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTNSRCReturn power sourceA *CHAR variable the command setsNo
RTNCHGReturn UPS chargeA *DEC variable the command setsNo
RTNLOADReturn load (FE/t)A *INT variable the command setsNo
RTNSTOREDReturn energy storedA *INT variable the command setsNo
RTNCAPReturn energy capacityA *INT variable the command setsNo
RTNDRVSTOReturn stored in drivesA *INT variable the command setsNo
RTNDRVCAPReturn drive capacityA *INT variable the command setsNo

Reports on the network's power: where it comes from, the UPS charge, the load and the energy stored. Any of the variables can be left out. See Power.

VariableGets
RTNSRC*UPS when any online UPS is running on its battery; otherwise *NETWORK when the network is up (online, or switching over to a standby controller); *NONE when it isn't
RTNCHGThe online UPSes' average charge, in percent; 0 with no UPS
RTNLOADWhat the network uses, in FE a tick, rounded
RTNSTOREDEnergy in the network's whole energy pool, in FE
RTNCAPThe pool's capacity, in FE
RTNDRVSTOThe part of the pool held in Energy Storage Drives, in FE
RTNDRVCAPThose drives' capacity, in FE

These are the figures the Network screen shows. The command sends no completion message. A program can also start the moment the power changes, through the *PWRUPS trigger event (see Jobs, scheduling and triggers).

DCL VAR(&SRC) TYPE(*CHAR) LEN(8)
DCL VAR(&CHG) TYPE(*DEC) LEN(5 1)
RTVPWRSTS RTNSRC(&SRC) RTNCHG(&CHG)
IF COND(&SRC *EQ '*UPS' *AND &CHG *LT 25) THEN(DO)
  SNDMSG MSG('UPS below 25%, shutting the deployers down') TOUSR(*ALL)
  CHGDEVSTS DEV(DEPLOYER01) STATUS(*DISABLE)
ENDDO
