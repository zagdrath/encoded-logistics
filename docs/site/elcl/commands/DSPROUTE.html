DSPROUTE

Command line only Firewall: None

Display Route Table

Syntax

DSPROUTE RTR(device name)

The first parameter can be given without its keyword, in that order: RTR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTRRouterDevice name
prompter field 10 long; F4 lists devices		Yes

DSPROUTE opens Display Route Table for a Router on your network: every network it can reach, with the next hop on the best path (direct, a network, or IX:name through an Exchange Switch), the path's cost and hops, where the entry came from and how long it has been so. The top line names the Router, its mode and how many routes it has. You type it at a command line; it doesn't run in a program.

SourceMeaning
*STATICThe Router's own Link Card links. They always win over learned routes.
*CONNECTEDA neighbouring Router's network.
*DYNAMICLearned through other Routers (a Router in *DYNAMIC mode).

A note under the table says when a dynamic Router last reconverged. The screen refreshes every two seconds; PageUp / PageDown roll it, F11 switches to the Router's neighbours (DSPNBR), and Enter goes back.

RTR is the Router's device name (F4 lists the devices). A name that isn't a Router on your network shows ELC2601. In a program, RTVRTE looks up one route. See Routers and Screens.
