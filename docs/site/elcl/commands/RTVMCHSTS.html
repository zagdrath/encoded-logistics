RTVMCHSTS

Command line and programs Firewall: VIEW

Retrieve Machine Status

Syntax

RTVMCHSTS MCH(device name) [RTNSTS(*CHAR variable)] [RTNRSN(*CHAR variable)] [RTNPCT(*INT variable)] [RTNFE(*INT variable)] [RTNFECAP(*INT variable)] [RTNRCP(*CHAR variable)]

The first parameter can be given without its keyword, in that order: MCH.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MCHMachineDevice name
prompter field 10 long; F4 lists devices		Yes
RTNSTSReturn statusA *CHAR variable the command setsNo
RTNRSNReturn reasonA *CHAR variable the command setsNo
RTNPCTReturn progress, percentA *INT variable the command setsNo
RTNFEReturn energy storedA *INT variable the command setsNo
RTNFECAPReturn energy capacityA *INT variable the command setsNo
RTNRCPReturn recipeA *CHAR variable the command setsNo

Reads what an Arcforge machine is doing, through the Small Wireless Bridge on it. MCH is the machine's device name, made from its type (ARCCRU01 for an Arc Crusher, ELECTR01 for an Electrolyzer). A name no device has is ELC1301; a device that isn't a bridged machine is ELC1318, and so is every machine while the Arcforge integration is off. See Arcforge.

VariableGetsWhen the machine can't be read
RTNSTS*IDLE, *RUNNING, *NOPOWER, *NOINPUT, *BLOCKED (output full), *DISABLED, *NOTFORMED, *FAULT or *UNKNOWN*OFFLINE
RTNRSNThe machine's own words for its state ("Crushing", "No fuel")blanks
RTNPCTProgress through the current operation, 0 to 100; -1 between operations-1
RTNFEFE stored (0 for a machine without FE)0
RTNFECAPFE capacity (0 without FE)0
RTNRCPWhat the current operation makes ("5 Bone Meal"); blanks when idleblanks

*OFFLINE means the bridge isn't on the network, or its machine is gone or not loaded; unlike RTVMCHSTAT, this command doesn't fail then. *DISABLED is a machine that's switched off, for instance with CHGMCHSTS. Text longer than your variable is cut to fit. The command sends no completion message.

DCL VAR(&STS) TYPE(*CHAR) LEN(10)
DCL VAR(&PCT) TYPE(*INT)
RTVMCHSTS MCH(ARCCRU01) RTNSTS(&STS) RTNPCT(&PCT)
IF COND(&STS *EQ '*NOPOWER') THEN(CHGMCHCFG MCH(ARCCRU01) PWRNET(*YES))

Machines (Arcforge)

RTVMCHSTAT RTVMCHLST CHGMCHSTS CHGMCHCFG
