ENDDO

Programs only Firewall: None Runs on a PLC with no network

End Do Group

Syntax

ENDDO

It takes no parameters.

ENDDO closes the innermost open DO group or DO loop: DOWHILE, DOUNTIL or DOFOR. At the end of a loop it sends the program back for the next pass; at the end of a plain DO group the program simply carries on after it. A FOREACH closes with ENDFOR and a SELECT with ENDSELECT instead.

An ENDDO whose innermost open block isn't a DO or a DO loop (nothing open, or a FOREACH, SELECT or SUBR) is ELC0009 ("ENDDO without matching DO").

  • After the ENDDO of an IF ... THEN(DO) group, an ELSE may follow.
  • After the ENDDO of a MONMSG ... EXEC(DO) group, another MONMSG for the same command may follow.
  • A MONMSG after any other ENDDO has no command to monitor (ELC0009).
DCL VAR(&I)   TYPE(*INT)
DCL VAR(&LVL) TYPE(*INT)
DOFOR VAR(&I) FROM(1) TO(4)
  RTVRSIN DEV(CTLIF01) SIDE(*NORTH) RTNLVL(&LVL)
  IF COND(&LVL *GT 0) THEN(DO)
    SNDPGMMSG MSG('Signal on pass' *BCAT %CHAR(&I))
    LEAVE
  ENDDO
  DLYTICK TICKS(20)
ENDDO
