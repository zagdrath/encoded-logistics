CHGLGT

Command line and programs Firewall: BUILD

Change Light

Syntax

CHGLGT DEV(*ALL | device name) [STATUS(*SAME | *ON | *OFF | *TOGGLE)] [LVL(*SAME | whole number)]

The first 2 parameters can be given without their keyword, in that order: DEV, STATUS.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVCage LightDevice name
a list of up to 32 values; prompter field 10 long; F4 lists devices		Yes*ALL
STATUSStatusSpecial valueNo*SAME*SAME, *ON, *OFF, *TOGGLE
LVLLight levelWhole numberNo*SAME*SAME

CHGLGT sets the network's half of a Cage Light's state, and its light level. A Cage Light has two inputs: the redstone at its block and its network state. Either one turns it on, so CHGLGT ... STATUS(*OFF) doesn't put out a light that redstone is holding on. How the light combines them is its Control setting, on its settings screen:

ControlLit when
Redstone (the default)It has a redstone signal, or its network state is on
InvertedIt has no redstone signal, or its network state is on
Always onAlways: STATUS has no visible effect (the network state is still kept)
Network onlyIts network state is on
  • STATUS(*ON) and *OFF set the network state; *TOGGLE flips it, light by light, so lights that started out different stay different. *SAME (the default) leaves it.
  • LVL sets the light level it gives while lit, 1-15. It is kept whatever the light's state and Control. A level outside 1-15 stops the command with ELC2401 before any light changes. *SAME leaves it.
  • DEV takes up to 32 names, or *ALL for every online Cage Light on the network (none found: nothing happens). Every named light is checked before any is changed: not there (ELC1301), offline (ELC1302) or not a Cage Light (ELC1303).

Unlike the Alarm Strobe and Speaker commands, CHGLGT works whatever the light's Control setting, since a Cage Light has no trigger to refuse network commands. It sends no completion message.

CHGLGT DEV(LGT01 LGT02) STATUS(*ON) LVL(15)
CHGLGT DEV(*ALL) STATUS(*TOGGLE)
CHGLGT LGT03 LVL(4)            /* dim it; on or off as it was */

See Cage Lights for the light itself, and STRSRN for the Alarm Strobes.
