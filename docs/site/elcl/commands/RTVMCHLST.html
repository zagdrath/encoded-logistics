RTVMCHLST

Command line and programs Firewall: VIEW

Retrieve Machine List

Syntax

RTVMCHLST [TYPE(*ALL | name (up to 10 characters))] [STATUS(*ALL | *IDLE | *RUNNING | *NOPOWER | *NOINPUT | *BLOCKED | *DISABLED | *NOTFORMED | *FAULT | *OFFLINE)] RTNLST(*LIST variable)

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
TYPEMachine typeName (up to 10 characters)
prompter field 64 long		No*ALL*ALL
STATUSStatusSpecial valueNo*ALL*ALL, *IDLE, *RUNNING, *NOPOWER, *NOINPUT, *BLOCKED, *DISABLED, *NOTFORMED, *FAULT, *OFFLINE
RTNLSTReturn listA *LIST variable the command setsYes

Lists the device names of the network's Arcforge machines (those with a Small Wireless Bridge on) into a *LIST variable, in Work with Devices' order.

  • TYPE: a machine's type code, the start of its device name (ARCCRU), or its full type ID ('arcforge:arc_crusher'). *ALL (the default) keeps every machine.
  • STATUS: keeps machines whose status, as RTVMCHSTS returns it, is the one you give: *IDLE, *RUNNING, *NOPOWER, *NOINPUT, *BLOCKED, *DISABLED, *NOTFORMED, *FAULT or *OFFLINE.

Nothing matching gives an empty list. The command sends no completion message. See Arcforge.

DCL VAR(&BROKEN) TYPE(*LIST)
DCL VAR(&MCH) TYPE(*CHAR) LEN(10)
RTVMCHLST STATUS(*FAULT) RTNLST(&BROKEN)
FOREACH VAR(&MCH) IN(&BROKEN)
  SNDMSG MSG(&MCH *BCAT 'has a fault') TOUSR(*SYSOPR)
ENDFOR
