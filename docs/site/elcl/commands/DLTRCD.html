DLTRCD

Programs only Firewall: None

Delete Record

Syntax

DLTRCD [OPNID(*NONE | name (up to 10 characters))]

The first parameter can be given without its keyword, in that order: OPNID.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
OPNIDOpen file identifierName (up to 10 characters)
prompter field 10 long		No*NONE*NONE

DLTRCD deletes the record the program last read from a declared file (RCVF or CHNRCD). It sends no message when the record is deleted.

  • No record last read is ELC2204 (nothing read yet, the end of the file reached, POSDBF or CLOF since, or that record already deleted, by this program or another job).
  • After it there's no record last read, so a second DLTRCD or an UPDRCD is ELC2204 until you read again. The next RCVF reads on to the record after the deleted one, so deleting as you read works.
  • Its relative record number isn't used again. To delete every record at once, use CLRPFM.
  • It needs *CHANGE on the library (ELC0401) and can't delete from ELSYS files (ELC0205).
PGM PARM(&BEFORE)
  DCL  VAR(&BEFORE) TYPE(*CHAR) LEN(14)   /* e.g. '00030 06:00:00' */
  DCLF FILE(ELGPL/ITEMHIST)
  DCL  VAR(&N) TYPE(*INT)
  /* Drop the history logged before a game time */
  DOWHILE COND('1')
    RCVF
    MONMSG MSGID(ELC2201) EXEC(LEAVE)
    IF COND(&LOGGED *GE &BEFORE) THEN(LEAVE)   /* key order: the rest are newer */
    DLTRCD
    CHGVAR VAR(&N) VALUE(&N + 1)
  ENDDO
  SNDPGMMSG MSG(%CHAR(&N) *BCAT 'records deleted')
ENDPGM
