RTVNBRSTS

Command line and programs Firewall: VIEW

Retrieve Neighbour Status

Syntax

RTVNBRSTS RTR(device name) NBR(name (up to 10 characters)) [RTNSTS(*CHAR variable)] [RTNCOST(*INT variable)] [RTNUPTIME(*INT variable)]

The first 2 parameters can be given without their keyword, in that order: RTR, NBR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
RTRRouterDevice name
prompter field 10 long; F4 lists devices		Yes
NBRNeighbourName (up to 10 characters)
prompter field 10 long		Yes
RTNSTSReturn statusA *CHAR variable the command setsNo
RTNCOSTReturn costA *INT variable the command setsNo
RTNUPTIMEReturn uptime (s)A *INT variable the command setsNo

Reports on one of a Router's neighbours: another Dynamic-mode Router it exchanges routes with, over a link or at an Exchange Switch. The neighbours are the ones DSPNBR lists. RTR is the Router's device name (ELC2601 when it isn't a Router on your network); NBR is the neighbour's network name (its SYSNAME), as DSPNBR shows it. A network that isn't one of the Router's neighbours is ELC2605.

VariableGets
RTNSTS*FULL (exchanging routes), *INIT (seen, not yet exchanging) or *DOWN
RTNCOSTThe cost of the hop to it: the override set with CHGNBR, or the one worked out from the link
RTNUPTIMESeconds it has been *FULL; 0 in any other state

The command sends no completion message. See Routers.

DCL VAR(&STS) TYPE(*CHAR) LEN(6)
RTVNBRSTS RTR(ROUTER01) NBR(ELNET03) RTNSTS(&STS)
IF COND(&STS *EQ '*DOWN') THEN(SNDMSG MSG('Lost ELNET03') TOUSR(*SYSOPR))
