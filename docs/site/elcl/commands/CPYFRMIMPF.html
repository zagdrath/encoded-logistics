CPYFRMIMPF

Command line and programs Firewall: None

Copy From Import File

Syntax

CPYFRMIMPF FROMSTMF(text) FILE(library/name) [MBROPT(*ADD | *REPLACE)]

The first 2 parameters can be given without their keyword, in that order: FROMSTMF, FILE.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
FROMSTMFFrom stream fileText
prompter field 40 long		Yes
FILETo fileLibrary/name
prompter field 21 long; F4 lists files		Yes
MBROPTReplace or add recordsSpecial valueNo*ADD*ADD, *REPLACE

CPYFRMIMPF reads a CSV file from the world save into a physical file's records: one you exported with CPYTOIMPF, or one you made in a spreadsheet. Done, it sends ELC2237 with how many records were added.

  • Where it's read from: <world>/encodedlogistics/libraries/<SYSNAME>/<name>.csv, the system's folder-sync folder. A file that isn't there is ELC2240.
  • FROMSTMF is a plain file name ending in .csv (letters, digits, _, . and -, no folders); anything else is ELC2245. Folder sync must be on (elcl.allowFolderSync), else ELC2241.
  • MBROPT(*ADD), the default, adds the rows to the records there; *REPLACE deletes those first.
  • Columns. If the first row is a heading (every cell in it the name of one of the file's fields, in any case and any order), the columns are matched to fields by name: fields it leaves out are blank, and it's not read as a record. Otherwise the columns are the file's fields in order, and every row is a record. Cells past the last field are ignored; a short row leaves the rest blank. Blank lines are skipped.
  • Values are taken as their field's type: a whole number for S, a number for P, 1 or 0 for L (blank is 0), a game timestamp for T (00012 06:30:15, 12 06:30 or Day 12 06:30; blank takes the time it's read in). Text too long for an A field is cut. Double quotes around a cell are taken off ("" inside is one quote).
  • All or nothing. A value that doesn't fit is ELC2243, with its row (counting the heading) and the field; a duplicate UNIQUE key ELC2203; too many records ELC2208; no room on the drives ELC0207. Then nothing is added, and with *REPLACE the old records stay.
  • The file must exist (make it with CRTPF first). Without a library it's looked for down your library list. It needs *CHANGE on the library (ELC0401); ELSYS files can't be imported into (ELC0205).
CPYFRMIMPF FROMSTMF('itemhist.csv') FILE(ELGPL/ITEMHIST) MBROPT(*REPLACE)
