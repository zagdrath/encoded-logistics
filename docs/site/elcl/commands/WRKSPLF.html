WRKSPLF

Command line only Firewall: None

Work with Spooled Files

Syntax

WRKSPLF [JOB(*ALL | name (up to 10 characters))]

The first parameter can be given without its keyword, in that order: JOB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
JOBJob nameName (up to 10 characters)
prompter field 28 long		No*ALL*ALL

WRKSPLF opens Work with Output: your spooled files, newest first, with the job that made each one (nnnnnn/JOBNAME), its user, pages (60 lines each), status (*RDY, *PRT once printed, *HLD) and when it was made. It's Main Menu option 8. You type it at a command line; it doesn't run in a program.

 WRKSPLF                        Work with Output               System:  ELNET01
                                                                Day 2  07:14:22

 Type options, press Enter.
   4=Delete   5=Display   6=Print

Opt  File        Job                   User        Pages  Status  Created
     NOCWALL     000118/NOCWALL        ZAGDRATH        1  *RDY    Day 2  07:13
     QPJOBLOG    000123/RESTOCK        ZAGDRATH        2  *RDY    Day 2  07:10
     INVLIST     000099/QPRTRPT        OPERATOR        6  *PRT    Day 1  18:44










 Parameters or command                                                   Bottom
 ===>

 F1=Help  F3=Exit  F5=Refresh  F9=Command Entry  F11=Sort  F12=Cancel

What makes a spooled file: compile listings (CRTELPGM, CRTPF, CHGPF, 14=Compile), printed members, PRTTXT, and RUNQRY OUTPUT(*PRINT) (file QPQUPRFIL). A system keeps elcl.spooledFileCap (default 200) spooled files; past that the oldest goes.

  • JOB(*ALL), the default, lists all of yours. Give a job's name (or number) to see only that job's files; Work with Active Jobs' 8=Spooled files opens it that way.
OptionWhat it does
4=DeleteDeletes it, after you confirm.
5=DisplayShows it a page at a time (Display Spooled File): PageUp / PageDown, F19 / F20 shift 40 columns.
6=PrintPrints it on the Line Printer (PRT01): ELC1301 when there's none, ELC1306 when it's out of paper.

F11 sorts by created, file or status. See Screens.
