STRSRN

Command line and programs Firewall: BUILD

Start Siren

Syntax

STRSRN DEV(*ALL | device name) [SOUND(*SAME | *WAIL | *YELP | *KLAXON | *BELL | *HORN | *BEEP | *NONE)] [MODE(*SAME | *SOLID | *SLOW | *MEDIUM | *FAST)]

The first 2 parameters can be given without their keyword, in that order: DEV, SOUND.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVAlarm StrobeDevice name
a list of up to 32 values; prompter field 10 long; F4 lists devices		Yes*ALL
SOUNDSoundSpecial valueNo*SAME*SAME, *WAIL, *YELP, *KLAXON, *BELL, *HORN, *BEEP, *NONE
MODELight modeSpecial valueNo*SAME*SAME, *SOLID, *SLOW, *MEDIUM, *FAST

STRSRN turns on the network's half of an Alarm Strobe's trigger: the lens lights in its light mode and its tone plays, looping, until ENDSRN turns it off again.

  • SOUND changes the strobe's tone, and it stays changed: the strobe's settings screen shows the new one. *WAIL, *YELP, *KLAXON, *BELL, *HORN and *BEEP are the six siren tones; *NONE makes it a silent, light-only beacon. *SAME (the default) keeps the tone it has.
  • MODE changes its light mode the same way: *SOLID, or flashing *SLOW, *MEDIUM or *FAST. *SAME keeps it.
  • Starting a strobe that's already on doesn't restart its tone, unless SOUND gives it a different one.

Strobes on one network that sound the same tone count their samples from the same moment, so a strobe you start joins the others in step. Its volume and range are set on its settings screen (the range at most signals.sirenMaxRange (default 96) blocks).

A strobe's Trigger setting decides whether it listens to the network:

TriggerSTRSRN / ENDSRN
Both (the default)Work; redstone at its block sets it off too
NetworkWork; redstone is ignored
RedstoneNamed in DEV, the command stops with ELC2408; DEV(*ALL) leaves it out

DEV takes up to 32 names, or *ALL for every online strobe on the network that takes network commands. Every named strobe is checked before any changes: not there (ELC1301), offline (ELC1302), not an Alarm Strobe (ELC1303) or Redstone-triggered (ELC2408). It sends no completion message.

STRSRN DEV(SRN01 SRN02) SOUND(*KLAXON) MODE(*FAST)
STRSRN DEV(*ALL) SOUND(*NONE) MODE(*SLOW)   /* every strobe, light only */

See Alarm Strobes for the tones and settings.
