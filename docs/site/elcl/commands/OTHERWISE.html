OTHERWISE

Programs only Firewall: None Runs on a PLC with no network

Otherwise

Syntax

OTHERWISE [CMD(command)]

The first parameter can be given without its keyword, in that order: CMD.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
CMDCommandCommand
F4 lists command		No

OTHERWISE is the last branch of a SELECT: it runs its CMD when none of the WHENs before it held. It is optional; without it a SELECT whose conditions all fail does nothing.

  • It comes after all the WHENs, at most once per SELECT. A WHEN or another OTHERWISE after it is ELC0001; an OTHERWISE outside a SELECT is ELC0009.
  • CMD holds one command, or CMD(DO) and a group of commands closed by ENDDO.
DCL VAR(&TYPE) TYPE(*CHAR) LEN(10)
DCL VAR(&USER) TYPE(*CHAR) LEN(16)
RTVJOBA RTNUSR(&USER) RTNTYPE(&TYPE)
SELECT
  WHEN COND(&TYPE *EQ '*INTER') THEN(SNDPGMMSG MSG('Running at a terminal'))
  OTHERWISE CMD(DO)
    SNDMSG MSG('Batch run finished') TOUSR(&USER)
    PRTTXT TEXT('Batch run finished')
  ENDDO
ENDSELECT
