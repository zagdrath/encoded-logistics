RMVJOBSCDE

Command line and programs Firewall: None

Remove Job Schedule Entry

Syntax

RMVJOBSCDE JOB(name (up to 10 characters))

The first parameter can be given without its keyword, in that order: JOB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
JOBJob nameName (up to 10 characters)
prompter field 10 long		Yes

RMVJOBSCDE removes a job schedule entry, so it doesn't run again. A batch job it already submitted carries on: end that with ENDJOB if you need to.

JOB is the entry's name as ADDJOBSCDE gave it (not a job number); no entry of that name is ELC0302. You may remove your own entries; removing another user's takes a security officer (ELC0401, naming *JOBCTL), except on a network with no Firewall or at SECLVL 10. Done: ELC0313. A *ONCE entry removes itself once it has run. Work with Job Schedule Entries option 4 runs this command after asking.

RMVJOBSCDE JOB(NIGHTLY)
