WRKF

Command line only Firewall: None

Work with Files

Syntax

WRKF [LIB(*CURLIB | name (up to 10 characters))]

The first parameter can be given without its keyword, in that order: LIB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LIBLibraryName (up to 10 characters)
prompter field 10 long; F4 lists libraries		No*CURLIB*CURLIB

WRKF opens Work with Files on your terminal: the physical files in one library, with their attribute (PF), record counts and text. It's Main Menu option 10. LIB(*CURLIB), the default, shows your current library. Like every screen command it's typed at a command line, not run in a program.

 WRKF                           Work with Files                System:  ELNET01
                                                                Day 2  07:14:22
 Library . . . . :   ZAGLIB
 Type options, press Enter.
   2=Change data  4=Delete  5=Display data  8=Display description

Opt  File        Attr  Chg   Records  Text
     ITEMHIST    PF            1,240  Item count history
5    STOCK       PF    *           3  Stock levels
     LOWSTOCK    PF                2  Query of ZAGLIB/STOCK

                                      Chg * = definition changed since made








 Parameters or command                                                   Bottom
 ===>

 F1=Help  F3=Exit  F5=Refresh  F6=Create  F9=Command Entry  F12=Cancel

Type an option next to one or more files and press Enter:

OptionWhat it does
2=Change dataOpens Update Data (UPDDTA) on the file.
4=DeleteDeletes the file and its records (DLTF), after you confirm.
5=Display dataShows the records in columns (DSPPFM).
8=Display descriptionShows its fields, key and size (DSPFD).
  • Chg * marks a file whose definition (the PF member it was made from) changed after the file was made. Option 14=Compile on that member in Work with Members makes it again, keeping its records (CHGPF).
  • F6 prompts CRTPF with the library already in its File field.
  • ELSYS's files are the network's own data, made as they're read: 5 and 8 work, 2 and 4 are refused with ELC0205.

Work with Members (WRKMBR) lists a library's files too, after its members (Type *FILE). See Screens and the database screens.

WRKF LIB(ZAGLIB)
WRKF LIB(ELSYS)
