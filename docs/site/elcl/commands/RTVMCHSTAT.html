RTVMCHSTAT

Command line and programs Firewall: VIEW

Retrieve Machine Statistics

Syntax

RTVMCHSTAT MCH(device name) [RTNOPS(*INT variable)] [RTNPRD(*INT variable)] [RTNCNS(*INT variable)] [RTNFLDPRD(*INT variable)] [RTNFLDCNS(*INT variable)] [RTNUPTIME(*INT variable)] [RTNOPM(*DEC variable)]

The first parameter can be given without its keyword, in that order: MCH.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MCHMachineDevice name
prompter field 10 long; F4 lists devices		Yes
RTNOPSReturn operationsA *INT variable the command setsNo
RTNPRDReturn items producedA *INT variable the command setsNo
RTNCNSReturn items consumedA *INT variable the command setsNo
RTNFLDPRDReturn fluid produced (mB)A *INT variable the command setsNo
RTNFLDCNSReturn fluid consumed (mB)A *INT variable the command setsNo
RTNUPTIMEReturn seconds runningA *INT variable the command setsNo
RTNOPMReturn operations a minuteA *DEC variable the command setsNo

Reads an Arcforge machine's running totals, as Work with Machines' statistics show them. MCH names the machine as for RTVMCHSTS (ELC1301, ELC1318). A machine that's gone or not loaded is ELC1302.

VariableGets
RTNOPSOperations completed
RTNPRDItems produced
RTNCNSItems consumed
RTNFLDPRDFluid produced, in mB
RTNFLDCNSFluid consumed, in mB
RTNUPTIMESeconds spent running
RTNOPMOperations a minute, recently (two decimals)

The totals are Arcforge's own: kept while the machine stands, lost when it's broken. The command sends no completion message.

DCL VAR(&OPS) TYPE(*INT)
DCL VAR(&OPM) TYPE(*DEC) LEN(7 2)
RTVMCHSTAT MCH(ELECTR01) RTNOPS(&OPS) RTNOPM(&OPM)
SNDPGMMSG MSG('ELECTR01:' *BCAT %CHAR(&OPS) *BCAT 'ops,' *BCAT %CHAR(&OPM) *BCAT 'a minute')
