DLTLIB

Command line and programs Firewall: None

Delete Library

Syntax

DLTLIB LIB(name (up to 10 characters))

The first parameter can be given without its keyword, in that order: LIB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LIBLibraryName (up to 10 characters)
prompter field 10 long; F4 lists libraries		Yes

DLTLIB deletes a library and everything in it: its source members, its programs, and its database files with their records. There's no confirmation on the command line (Work with Libraries option 4 asks first) and no undo, so save the library to a diskette with SAVLIB first if you may want it back.

  • Only the library's owner or a security officer may delete it, whatever its public authority: anyone else gets ELC0401 (naming *OWNER).
  • ELSYS and ELGPL can't be deleted: ELC0205.
  • With folder sync on, the members' files move to the .deleted folder beside them.

Done: ELC0211. A program already running from the library carries on to its end; a later CALL of it is ELC0203.

DLTLIB LIB(ZAGTEST)
