EDTMBR

Command line only Firewall: None

Edit Member

Syntax

EDTMBR MBR(library/name)

The first parameter can be given without its keyword, in that order: MBR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MBRMemberLibrary/name
prompter field 21 long; F4 lists members		Yes

EDTMBR opens a source member in the full-screen source editor, as Work with Members option 2 does. Give MBR(LIB/NAME). With a bare name, or with *LIBL/ or *CURLIB/ in front, it opens the member of that name in your current library (it doesn't search the library list). The member must exist already: make it with CRTMBR (or F6 on Work with Members).

The editor opens read-only (Display Member) when:

  • the member is in ELSYS;
  • you may not change its library: it isn't yours, its public authority is *USE, and you aren't a security officer;
  • someone else has it open. You see ELC0208: one user edits a member at a time, and the lock goes when they leave the editor or close their terminal.

Each Enter checks the statements you changed and shows the first error reversed. The SAVE and FILE editor commands write the member: ELC0213. A save that needs more network storage than the drives have free is ELC0207, and a member longer than elcl.maxSourceLines (default 5000) lines is ELC0004. Saving doesn't compile: the program stays as it was until you compile the member again (CRTELPGM, or option 14).
