WRKMBR

Command line only Firewall: None

Work with Members

Syntax

WRKMBR [LIB(*CURLIB | name (up to 10 characters))]

The first parameter can be given without its keyword, in that order: LIB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LIBLibraryName (up to 10 characters)
prompter field 10 long; F4 lists libraries		No*CURLIB*CURLIB

Work with Members lists a library's source members (type ELCLP for a program's source, PF for a file's definition), then its database files (type *FILE). LIB(*CURLIB), the default, is your current library. Work with Libraries option 12 opens it too. Type an option next to a member and press Enter:

OptionWhat it does
2Edit it in the source editor (EDTMBR).
3Copy it to another library or name, in a window (CPYMBR).
4Delete it, after you confirm (DLTMBR).
5Display it: the editor, read-only.
6Print the source to a spooled file (see WRKSPLF).
7Rename it, in a window (RNMMBR).
9Submit its program as a batch job: SBMJOB's prompter with CMD(CALL PGM(LIB/MEMBER)) and JOB(MEMBER) filled in, so you can add parameters or pick a host first.
14Compile it. An ELCLP member: CRTELPGM. A PF member: CRTPF, or CHGPF when its file is there already (which keeps the records). The listing goes to Work with Output.
16Call its program in your interactive job: CALL's prompter with PGM(LIB/MEMBER) filled in.

Options 9 and 16 need the member compiled since it last changed. If it isn't, the message line says so, and Enter compiles it (as 14) and then goes on to the prompter. The Chg column shows * when the source changed after its program (or file) was made.

On a file: 2=Change data (UPDDTA), 4=Delete (DLTF), 5=Display data (DSPPFM), 8=Display description (DSPFD). In ELSYS, options 2, 4 and 7 are refused with ELC0205: browse with 5 and copy with 3. F6 prompts CRTMBR (SRCTYPE(PF) for a file's definition); F11 sorts the members by name, by changed or by text.
