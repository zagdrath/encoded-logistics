WRKJOB

Command line only Firewall: None

Work with Job

Syntax

WRKJOB [JOB(* | name (up to 10 characters))]

The first parameter can be given without its keyword, in that order: JOB.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
JOBJob nameName (up to 10 characters)
prompter field 28 long; F4 lists jobs		No**

Work with Job is a menu for one job. JOB(*), the default, is your own interactive job; otherwise give a job's number (000123), its name while only one job has it, or 000123/USER/NAME. Ended jobs whose logs are still kept can be named too. An unknown or ambiguous job is ELC0302. Work with Active Jobs option 5 opens it for the job on that row.

Type a number on the command line and press Enter, or click an option:

OptionShows
1Its status attributes: name, user, number, status, host and budget used.
2Its definition attributes: type (*INTER or *BATCH), priority, whether it logs its commands, and user.
4Its spooled files (WRKSPLF).
10Its job log (DSPJOBLOG).
11Its call stack: the programs it's running, each with the line it has reached.
30All of them, one after another.

To change, hold, release or end the job, use CHGJOB, HLDJOB, RLSJOB and ENDJOB, or Work with Active Jobs. See Jobs, scheduling and triggers.
