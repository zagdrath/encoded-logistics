ENDPLC

Command line and programs Firewall: BUILD

End PLC

Syntax

ENDPLC DEV(device name)

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVPLCDevice name
prompter field 10 long; F4 lists devices		Yes

Stops a Programmable Logic Controller's program, as F7 (STOP) on its status screen does. The program halts where it is, every output goes to 0, and its RETAIN variables keep their values for the next start. The program stays loaded: STRPLC runs it again from the top.

DEV is the PLC's device name on your network (ELC1301, ELC1303 for a device that isn't a PLC). Stopping a PLC that isn't running is fine. On success the command sends ELC1508. See Programmable Logic Controller.

ENDPLC DEV(PLC01)
SNDPLCPGM PGM(PLCLIB/PUMPCTL2) DEV(PLC01) RUN(*NO)
STRPLC DEV(PLC01)

PLCs

RTVSNSVAL SNDPLCPGM STRPLC
