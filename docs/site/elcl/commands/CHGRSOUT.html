CHGRSOUT

Command line and programs Firewall: BUILD Runs on a PLC with no network

Change Redstone Output

Syntax

CHGRSOUT DEV(*SELF | device name) SIDE(*NORTH | *SOUTH | *EAST | *WEST | *UP | *DOWN | *ALL) LVL(whole number)

The first 3 parameters can be given without their keyword, in that order: DEV, SIDE, LVL.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes*SELF
SIDESideSpecial valueYes*NORTH, *SOUTH, *EAST, *WEST, *UP, *DOWN, *ALL
LVLLevelWhole number
0 to 15		Yes

Sets the redstone level a Control Interface or Programmable Logic Controller gives out on one face, or on all six with SIDE(*ALL). LVL is 0 (off) to 15; a value outside that is ELC0004. RTVRSIN reads what arrives. See Control Interface and Programmable Logic Controller.

DEV and SIDE work as for RTVRSIN: a device name or *SELF (a PLC's own program only), and world directions. A name no device has is ELC1301, a device that's neither kind is ELC1303, and an offline one is ELC1302, in which case nothing changes.

The level is kept until it's set again. A Control Interface gives it out only while it's online. A PLC gives its outputs out while it's powered; stopping it (ENDPLC, F7), starting it from the top (STRPLC, F6) or loading a program sets them all to 0, and a fault keeps or drops them as plc.plcFaultOutputs (default HOLD) says. The command sends no completion message.

On a PLC#

CHGRSOUT DEV(*SELF) runs on a PLC with no network (the badge above). In a program compiled for a PLC on its own, any DEV other than *SELF is ELC1502. The PLC's I/O screen shows which program line last set each face. See Redstone, PLCs and signals from ELCL.

DCL VAR(&ON) TYPE(*LGL)
DOWHILE COND('1')
  CHGVAR VAR(&ON) VALUE(*NOT &ON)
  IF COND(&ON) THEN(CHGRSOUT DEV(*SELF) SIDE(*ALL) LVL(15))
  ELSE CMD(CHGRSOUT DEV(*SELF) SIDE(*ALL) LVL(0))
  DLYTICK TICKS(10)
ENDDO

From a batch job, light a lamp wired to a Control Interface:

CHGRSOUT DEV(CTLIF01) SIDE(*UP) LVL(15)
DLYJOB DLY(30)
CHGRSOUT DEV(CTLIF01) SIDE(*UP) LVL(0)
