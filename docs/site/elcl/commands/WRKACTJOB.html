WRKACTJOB

Command line only Firewall: None

Work with Active Jobs

Syntax

WRKACTJOB

It takes no parameters.

Work with Active Jobs lists the system's script jobs: the interactive job of each terminal session (type INT, its host the terminal) and every batch job that hasn't ended (type BCH, its host the job host running it, or the host it asked for while it waits). It's also option 6 on the main menu.

The Status column shows *ACTIVE (running), *WAIT (waiting, in DLYJOB for instance), *JOBQ (on the job queue, not started) or *HELD. Budget is how much of its own per-tick budget the job used on the last tick. Row 2 adds up the budget all jobs used, the time since the screen opened, the active jobs and the job hosts busy. The screen doesn't refresh by itself: press F5 (which also starts the elapsed time again). F11 sorts by job, user or status.

OptionWhat it does
2Change its priority and command logging in a window (CHGJOB).
3Hold it (HLDJOB).
4End it, after you confirm (ENDJOB *CNTRLD; F11 in the confirmation ends it *IMMED).
5Work with it: status, definition, spooled files, log, call stack (WRKJOB).
6Release a held job (RLSJOB).
8Its spooled files (WRKSPLF).

Ended jobs leave the list; their logs stay, and DSPJOBLOG JOB() shows them.
