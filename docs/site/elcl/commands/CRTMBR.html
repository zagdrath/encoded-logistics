CRTMBR

Command line and programs Firewall: None

Create Member

Syntax

CRTMBR MBR(library/name) [TEXT(*BLANK | text)] [SRCTYPE(ELCLP | PF | name (up to 10 characters))]

The first 2 parameters can be given without their keyword, in that order: MBR, TEXT.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MBRMemberLibrary/name
prompter field 21 long; F4 lists members		Yes
TEXTText 'description'Text
prompter field 48 long		No*BLANK*BLANK
SRCTYPESource typeName (up to 10 characters)
prompter field 10 long		NoELCLPELCLP, PF

CRTMBR makes an empty source member in a library. Open it with EDTMBR to write it.

  • MBR(LIB/NAME): give the library. A bare name goes in the first library on your library list that already has a member of that name (which is then ELC0204), else in your current library. The name is up to 10 characters, a letter then letters, digits, _, @, # or $ (ELC0103 otherwise).
  • SRCTYPE(ELCLP), the default, is a program's source (compile it with CRTELPGM); SRCTYPE(PF) is a physical file's definition (compile it with CRTPF). Any other type is ELC0103.
  • TEXT is its description, up to 48 characters, shown on Work with Members.

The library must be one you may change: ELSYS is ELC0205, and a library that isn't yours, with public authority *USE, is ELC0401 unless you're a security officer. A member of that name already there is ELC0204. An empty member takes no storage. Done: ELC0214.

CRTMBR MBR(ELGPL/MYLOG) TEXT('Item log definition') SRCTYPE(PF)
CRTMBR MBR(ELGPL/LOGIT) TEXT('Writes the item log')

See Libraries and the editor.
