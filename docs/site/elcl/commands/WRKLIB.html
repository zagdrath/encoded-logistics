WRKLIB

Command line only Firewall: None

Work with Libraries

Syntax

WRKLIB

It takes no parameters.

Work with Libraries lists every library on the system you're signed on to, with its type (*PROD, *TEST, or *SYS for ELSYS) and its text. It's also option 5 on the main menu. Type an option next to a library and press Enter:

OptionWhat it does
2Change its text and public authority (*USE or *CHANGE) in a window. Runs CHGLIB.
4Delete it, after you confirm. Runs DLTLIB.
5Display its attributes: type, text, owner, public authority, how many members it holds, their size in characters, and when it was made.
12Work with its members, then its files (WRKMBR).

F6 prompts CRTLIB to make a new library. ELSYS holds the samples and the system files and is read-only (changing or deleting it is ELC0205); ELGPL is the general purpose library, open to everyone. To work with a library's database files alone, use WRKF.
