ADDLSTE

Programs only Firewall: None Runs on a PLC with no network

Add List Element

Syntax

ADDLSTE LIST(*LIST variable) VALUE(text) [POS(*END | whole number)]

The first 2 parameters can be given without their keyword, in that order: LIST, VALUE.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
LISTListA *LIST variable the command setsYes
VALUEValueText
prompter field 32 long		Yes
POSPositionWhole number
1 to 4096		No*END*END

ADDLSTE adds one element to a *LIST variable: at the end, or at a position you give, moving the elements from there on one place down. Elements are text; to add a number, convert it with %CHAR (VALUE(%CHAR(&N))), since a numeric variable is ELC0103 here (a literal number is taken as text).

  • VALUE's trailing blanks are dropped, so adding a *CHAR(64) variable holding 'minecraft:stone' adds just minecraft:stone.
  • POS(*END), the default, adds after the last element.
  • POS(n) puts the new element at position n (from 1): POS(1) adds it first, POS(%SIZE(&LIST) + 1) is the same as *END. A position past that, or below 1, is ELC0006 ("List index n is out of range (size s)") when it runs; a literal below 1 or above elcl.maxListSize is ELC0004 when you compile.
  • A list holds at most elcl.maxListSize (default 4096) elements. Adding to a full list is ELC0015.
  • Duplicates are allowed; ADDLSTE doesn't check what is already there.

ADDLSTE sends no message. Read a list with %SIZE, %ELEM and FOREACH; take elements out with RMVLSTE and CLRLST. More on the types.

DCL VAR(&WATCH) TYPE(*LIST)
DCL VAR(&ITEM)  TYPE(*CHAR) LEN(64)
DCL VAR(&N)     TYPE(*INT)
ADDLSTE LIST(&WATCH) VALUE('minecraft:iron_ingot')
ADDLSTE LIST(&WATCH) VALUE('minecraft:gold_ingot')
ADDLSTE LIST(&WATCH) VALUE('minecraft:diamond') POS(1)
FOREACH VAR(&ITEM) IN(&WATCH)
  RTVITMCNT ITEM(&ITEM) RTNCOUNT(&N) NOTFND(*ZERO)
  PRTTXT TEXT(&ITEM *BCAT %CHAR(&N))
ENDFOR
