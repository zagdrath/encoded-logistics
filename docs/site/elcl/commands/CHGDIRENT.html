CHGDIRENT

Command line and programs Firewall: BUILD

Change Directory Entry

Syntax

CHGDIRENT DEV(device name) PUBLISH(*YES | *NO)

The first 2 parameters can be given without their keyword, in that order: DEV, PUBLISH.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes
PUBLISHPublishedSpecial valueYes*YES, *NO

Publishes a device of your network on its Directory Servers, so other networks can reach it by its qualified name (ELNET01/CTLIF01), or stops publishing it. WRKDIR's 2=Publish and 3=Unpublish do the same. Only published devices can be found from other networks; see RTVDIRENT for everything else a remote lookup needs.

DEV is a device on your network (ELC1301 when there's none by that name). The change goes to every Directory Server (block or rack) on the network; with none, the command fails with ELC2616. On success it sends ELC2617 (published) or ELC2618 (no longer published).

A device is published by its name: after RNMDEV, publish the new name and unpublish the old one. See Exchange Switch and Directory Server.

CHGDIRENT DEV(CTLIF01) PUBLISH(*YES)
CHGDIRENT DEV(UPS01) PUBLISH(*NO)
