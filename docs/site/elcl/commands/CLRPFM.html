CLRPFM

Command line and programs Firewall: None

Clear Physical File Member

Syntax

CLRPFM FILE(library/name)

The first parameter can be given without its keyword, in that order: FILE.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
FILEFileLibrary/name
prompter field 21 long; F4 lists files		Yes

CLRPFM deletes every record in a physical file and keeps the file, its format and its definition. Done, it sends ELC2234 with how many records went. The storage they took is freed.

  • Without a library, the file is looked for down your library list.
  • Relative record numbers carry on from where they were: the next record written doesn't get number 1 again.
  • It needs *CHANGE on the library (ELC0401); ELSYS's files can't be cleared (ELC0205).

To replace a file's records with others in one go, CPYF and CPYFRMIMPF take MBROPT(*REPLACE). To delete the file itself, use DLTF.

CLRPFM FILE(ELGPL/ITEMHIST)
