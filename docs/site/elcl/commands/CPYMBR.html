CPYMBR

Command line and programs Firewall: None

Copy Member

Syntax

CPYMBR FROM(library/name) TO(library/name)

The first 2 parameters can be given without their keyword, in that order: FROM, TO.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
FROMFrom memberLibrary/name
prompter field 21 long; F4 lists members		Yes
TOTo memberLibrary/name
prompter field 21 long		Yes

CPYMBR copies a source member, with its type, text and every line (sequence numbers and change dates included), to a new member in the same or another library. It's the way to take a sample out of ELSYS and make it your own.

  • FROM can be in any library, ELSYS among them: reading needs no authority.
  • TO must be a library you may change (ELSYS is ELC0205; someone else's *USE library is ELC0401) and a name not taken there: copying over an existing member is ELC0204, so delete it first with DLTMBR if you mean to replace it. Give both libraries: a bare name is looked for down your library list.
  • The copy takes network storage like any member: ELC0207 when the drives haven't room for it.

Only the source is copied. A program compiled from FROM stays where it is; compile the copy with CRTELPGM (or Work with Members option 14) to make one from it. Done: ELC0215.

CPYMBR FROM(ELSYS/RESTOCK) TO(ZAGLIB/RESTOCK)
CRTELPGM PGM(ZAGLIB/RESTOCK)

Libraries, members and programs
