RTVSYSVAL

Command line and programs Firewall: None

Retrieve System Value

Syntax

RTVSYSVAL SYSVAL(name (up to 10 characters)) RTNVAR(*CHAR variable)

The first 2 parameters can be given without their keyword, in that order: SYSVAL, RTNVAR.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
SYSVALSystem valueName (up to 10 characters)
prompter field 10 long; F4 lists sysvals		Yes
RTNVARReturn variableA *CHAR variable the command setsYes

RTVSYSVAL puts a system value's current setting (its default, if nobody has changed it) into a *CHAR variable, as text: QMAXJOB gives 16, PHOSPHOR gives *GREEN. The longest values are eight characters, so LEN(10) is enough. Use %INT to turn a number into an *INT.

SYSVAL is one of SYSNAME, DATFMT, SECLVL, QMAXJOB, LOGRTN, CRFLOGRTN and PHOSPHOR (see WRKSYSVAL for what each means); any other name is ELC0103. Anyone may read them.

DCL VAR(&NAME) TYPE(*CHAR) LEN(10)
DCL VAR(&MAX)  TYPE(*CHAR) LEN(10)
DCL VAR(&JOBS) TYPE(*INT)
RTVSYSVAL SYSVAL(SYSNAME) RTNVAR(&NAME)
RTVSYSVAL SYSVAL(QMAXJOB) RTNVAR(&MAX)
CHGVAR VAR(&JOBS) VALUE(%INT(&MAX))
SNDPGMMSG MSG(&NAME *BCAT 'runs up to' *BCAT %CHAR(&JOBS) *BCAT 'batch jobs')

To change a value, use CHGSYSVAL.

System values, save and restore

WRKSYSVAL CHGSYSVAL SAVLIB RSTLIB
