RTVCHSSTS

Command line and programs Firewall: VIEW

Retrieve Chassis Status

Syntax

RTVCHSSTS DEV(device name) RTNLIST(*LIST variable) [RTNSTS(*CHAR variable)]

The first parameter can be given without its keyword, in that order: DEV.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
DEVDeviceDevice name
prompter field 10 long; F4 lists devices		Yes
RTNLISTReturn listA *LIST variable the command setsYes
RTNSTSReturn statusA *CHAR variable the command setsNo

Reports on a chassis: a Chassis Switch (CSW01), Blade Enclosure (BLD01) or Optical Transport Shelf (OTS01), by its device name. It returns every bay, empty ones included, as WRKHW with F11 shows them. A name that isn't a chassis on your network (or no device at all) is ELC2701. See Modular chassis.

RTNLIST gets one element per bay: its label, the part in it (*NONE when empty) and its state.

A SUPERVISOR_CARD *ACTIVE
B SUPERVISOR_CARD *STANDBY
P4 *NONE *EMPTY

A bay's state is one of *ONLINE, *ACTIVE, *STANDBY, *FAILED, *EMPTY, *OFFLINE or *PROTECT, as WRKHW shows it. RTNSTS gets the chassis as a whole: *ONLINE, *DEGRADED (working, with a warning) or *FAULT (in a fault, or offline). When it's degraded the command also sends the warning ELC2702, with the reason; otherwise it sends no message.

DCL VAR(&BAYS) TYPE(*LIST)
DCL VAR(&BAY) TYPE(*CHAR) LEN(40)
DCL VAR(&STS) TYPE(*CHAR) LEN(10)
RTVCHSSTS DEV(CSW01) RTNLIST(&BAYS) RTNSTS(&STS)
IF COND(&STS *NE '*ONLINE') THEN(DO)
  FOREACH VAR(&BAY) IN(&BAYS)
    IF COND(%SCAN('*FAILED' &BAY) *GT 0) THEN(SNDMSG MSG('CSW01 bay failed:' *BCAT &BAY) TOUSR(*SYSOPR))
  ENDFOR
ENDDO
