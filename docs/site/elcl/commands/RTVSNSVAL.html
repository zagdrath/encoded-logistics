RTVSNSVAL

Command line and programs Firewall: VIEW Runs on a PLC with no network

Retrieve Sensor Value

Syntax

RTVSNSVAL MODULE(whole number) [TYPE(*ANY | *PRESENCE | *INVENTORY | *FLUID | *LIGHT | *TIMER)] [DEV(*SELF | device name)] [RTNVAL(*DEC variable)] [RTNSTS(*CHAR variable)] [RTNAUX(*CHAR variable)]

The first parameter can be given without its keyword, in that order: MODULE.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MODULEModule slotWhole number
1 to 4		Yes
TYPEModule typeSpecial valueNo*ANY*ANY, *PRESENCE, *INVENTORY, *FLUID, *LIGHT, *TIMER
DEVPLCDevice name
prompter field 10 long; F4 lists devices		No*SELF*SELF
RTNVALReturn valueA *DEC variable the command setsNo
RTNSTSReturn statusA *CHAR variable the command setsNo
RTNAUXReturn extra valueA *CHAR variable the command setsNo

Reads one of a Programmable Logic Controller's sensor modules. A PLC has four module slots; MODULE is the slot, 1 to 4. Each read is taken fresh, at the moment the command runs. See Programmable Logic Controller.

ModuleTYPERTNVALRTNAUX
Presence Sensor*PRESENCEPlayers or mobs (as set in the Modules screen) within its radiusThe nearest one's name
Inventory Sensor*INVENTORYHow full the container on its face is, in percent, slot by slot as a comparator sees itThe number of items in it
Fluid Sensor*FLUIDHow full the tank on its face is, in percentThe amount, in mB
Light Sensor*LIGHTThe light level at the PLC, 0 to 15*DAY or *NIGHT
Timer Module*TIMERThe game time, in ticksThe day and time (Day 2 14:32)

An Inventory or Fluid Sensor's face is the block behind the PLC unless its setting in the Modules screen names another face; a Presence Sensor's radius and what it counts are set there too. TYPE(*ANY) (the default) reads whatever is in the slot; any other TYPE requires that kind of module there.

Errors or a status#

RTNSTS decides how problems come back:

  • With RTNSTS, nothing fails: RTNSTS gets *OK, *NOMODULE (an empty slot, or a module of another kind than TYPE) or *NOTARGET (an Inventory or Fluid Sensor with no container or tank on its face; RTNAUX then names the face, *WEST). RTNVAL is 0 unless the status is *OK.
  • Without RTNSTS, an empty or wrong slot is ELC1501 and a sensor with nothing to read is ELC1503.

The command sends no completion message.

Where it runs#

DEV(*SELF) (the default) is the PLC running the program, and that works with no network: RTVSNSVAL is one of the commands a PLC on its own can run (the badge above). From a batch job, or from another PLC, DEV(PLC01) reads a PLC on the same network by name (ELC1301 for no such device, ELC1303 for one that isn't a PLC). *SELF outside a PLC's own program is ELC1301, and in a program for a PLC on its own any other DEV is ELC1502. See Redstone, PLCs and signals from ELCL.

DCL VAR(&WHO) TYPE(*DEC) LEN(5 0)
DCL VAR(&STS) TYPE(*CHAR) LEN(10)
DOWHILE COND('1')
  RTVSNSVAL MODULE(1) TYPE(*PRESENCE) RTNVAL(&WHO) RTNSTS(&STS)
  IF COND(&STS *EQ '*OK' *AND &WHO *GT 0) THEN(CHGRSOUT DEV(*SELF) SIDE(*ALL) LVL(15))
  ELSE CMD(CHGRSOUT DEV(*SELF) SIDE(*ALL) LVL(0))
  DLYTICK TICKS(10)
ENDDO

From a batch job, check a networked PLC's tank:

DCL VAR(&PCT) TYPE(*DEC) LEN(5 0)
RTVSNSVAL MODULE(2) TYPE(*FLUID) DEV(PLC01) RTNVAL(&PCT)
IF COND(&PCT *LT 10) THEN(SNDMSG MSG('PLC01 tank under 10%') TOUSR(*SYSOPR))
