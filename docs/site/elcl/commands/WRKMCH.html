WRKMCH

Command line only Firewall: None

Work with Machines

Syntax

WRKMCH

It takes no parameters.

WRKMCH opens Work with Machines: the network's Arcforge machines that have a Small Wireless Bridge on them, with each one's device name, machine type, status (bright when it needs attention), progress, energy and rate (operations a minute). It's Main Menu option 9. You type it at a command line; it doesn't run in a program. Without Arcforge, or with no bridged machines, the list is empty. See Arcforge.

OptionWhat it does
2=ChangeA window with the machine's redstone mode, auto-eject, power from network and the Gateway that feeds it; F4 steps through each one's values. Enter runs CHGMCHCFG with what you changed.
5=DisplayEverything about the machine: its statistics and settings.
7=Enable/DisableTurns it the other way to how it is (CHGMCHSTS).
8=SidesFor a single-block machine: a window with each side's mode, F4 stepping through the modes; CHGMCHCFG for each side changed.

Looking needs the Firewall's view permission; changing (2, 7, 8) needs its build permission, as the commands do. In a program, RTVMCHLST, RTVMCHSTS and RTVMCHSTAT read the same information. See Screens.
