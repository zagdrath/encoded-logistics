CHGMCHSTS

Command line and programs Firewall: BUILD

Change Machine Status

Syntax

CHGMCHSTS MCH(device name) STATUS(*ENABLE | *DISABLE)

The first 2 parameters can be given without their keyword, in that order: MCH, STATUS.

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
MCHMachineDevice name
prompter field 10 long; F4 lists devices		Yes
STATUSStatusSpecial valueYes*ENABLE, *DISABLE

Switches an Arcforge machine off or on through Arcforge's remote switch. A machine switched off stops as a redstone stop would, keeps what's in it, and shows *DISABLED in RTVMCHSTS and Work with Machines. *ENABLE lets it run again.

MCH names the machine as for RTVMCHSTS (ELC1301, ELC1318). A machine that's gone or not loaded is ELC1302; an unformed multiblock is ELC1319; a machine without the switch is ELC1320; one that refuses is ELC1321. Switching it to the state it's already in is fine.

The command sends no completion message, even at the command line. See Arcforge.

DCL VAR(&MCHS) TYPE(*LIST)
DCL VAR(&MCH) TYPE(*CHAR) LEN(10)
RTVMCHLST TYPE(ARCCRU) RTNLST(&MCHS)
FOREACH VAR(&MCH) IN(&MCHS)
  CHGMCHSTS MCH(&MCH) STATUS(*DISABLE)
ENDFOR

Machines (Arcforge)

RTVMCHSTS RTVMCHSTAT RTVMCHLST CHGMCHCFG
