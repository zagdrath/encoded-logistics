RTVCRFLOG

Command line and programs Firewall: VIEW

Retrieve Craft Log

Syntax

RTVCRFLOG [ITEM(*ALL | item id)] [STATUS(*ALL | *DONE | *FAILED | *CANCELLED)] [MAX(*NOMAX | whole number)] RTNLST(*LIST variable)

Parameters

KeywordPromptTakesRequiredDefaultSpecial values
ITEMItemItem ID
prompter field 64 long; F4 lists items		No*ALL*ALL
STATUSStatusSpecial valueNo*ALL*ALL, *DONE, *FAILED, *CANCELLED
MAXMaximum jobsWhole number
1 to 999		No*NOMAX*NOMAX
RTNLSTReturn listA *LIST variable the command setsYes

Lists ended crafting jobs from the network's crafting history: their IDs (C0042), newest first, into a *LIST variable. The history keeps the last CRFLOGRTN jobs (a system value; default elcl.craftLogRetention (default 200)); Work with Crafting Jobs' F10 shows the same records.

  • ITEM: only jobs that made this item (ID forms as in RTVITMCNT; an unknown ID is ELC1201). *ALL (the default) keeps every job.
  • STATUS: *DONE, *FAILED or *CANCELLED keeps only jobs that ended that way.
  • MAX: keeps the newest n that pass the other two.

No matching job gives an empty list. Pass an ID from the list to RTVCRFSTS to see how far that job got. The command sends no completion message.

DCL VAR(&FAILED) TYPE(*LIST)
DCL VAR(&JOB) TYPE(*CHAR) LEN(10)
DCL VAR(&PCT) TYPE(*DEC) LEN(5 1)
RTVCRFLOG STATUS(*FAILED) MAX(5) RTNLST(&FAILED)
FOREACH VAR(&JOB) IN(&FAILED)
  RTVCRFSTS CRFJOB(&JOB) RTNPCT(&PCT)
  SNDPGMMSG MSG(&JOB *BCAT 'failed at' *BCAT %CHAR(&PCT) *TCAT '%')
ENDFOR

Crafting

STRCRAFT RTVCRFSTS ENDCRAFT RTVSCHLST RTVCRFSTP
