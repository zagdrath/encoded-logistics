DSPOPT

Command line only Firewall: None

Display Optical Status

Syntax

DSPOPT

It takes no parameters.

DSPOPT opens Display Optical Status: the network's optical gear (Optical Multiplexers, Optical Amplifiers and Optical Transport Shelfs) and their spans. Each span shows its path, length, the lanes it delivers, the lanes lost, signal quality (100% less 4% for each lane lost) and its 1+1 protection; under them, the last protection switch. The top line names the network and counts the shelves, multiplexers and amplifiers. You type it at a command line; it doesn't run in a program.

The screen refreshes every two seconds; PageUp / PageDown roll it. F10 shows the channels instead (each device's channels, the network on each, the far end, lanes and whether it's up); F10 again goes back. Enter goes back.

In a program, RTVOPTSTS reads the same figures, and CHGPROT switches a protected span's path. See Optical networking and Screens.

 OTS01-OTS02   protect      488      32     2      92%  *ACTIVE
 MUX01-MUX02   line         301      32     0     100%  -
 MUX02-AMP01   line         290      31     1      96%  -
