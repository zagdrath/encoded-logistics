WRKTRGEVT

Command line only Firewall: None

Work with Trigger Events

Syntax

WRKTRGEVT

It takes no parameters.

Work with Trigger Events lists the system's triggers: name, event, the item or device it watches, its value, the program it runs and its status (*ACTIVE or *HELD). It's also option 12 on the main menu. Type an option next to a trigger:

OptionWhat it does
2Change it: ADDTRGEVT's prompter with its values. Enter removes the trigger and adds it again as you changed it, so it comes back *ACTIVE and takes a fresh first look at its condition.
3Hold it (HLDTRGEVT); on a held trigger, release it (RLSTRGEVT).
4Remove it, after you confirm (RMVTRGEVT).

F6 prompts ADDTRGEVT to add a trigger. Hold and release send no message: the status column shows the change.
