Every message an ELCL command, program or screen sends. &1, &2 and so on stand for the details filled in when it's sent. Severity 20 and above is an error: in a program, a MONMSG can catch it, otherwise it ends the program. USR messages are your own, sent with SNDPGMMSG.

ELC00xx: Language and runtime

Raised by the compiler and while a program runs: syntax, undeclared variables, values that don't fit their type, division by zero, list limits, call depth. A compile that gives any message of severity 20 or more makes no program; ELC0008 is a warning and the program is still created.

USRxxxx: your own messages

Sent with SNDPGMMSG: the default ID is USR0001, and MSGID(USRnnnn) picks another. The text is whatever MSG() says. MSGTYPE(*INFO) (the default) only logs it; MSGTYPE(*ESCAPE) makes it an error of severity 30 that ends the program unless a MONMSG catches it. MONMSG MSGID(USR0000) catches every USR message, and MONMSG MSGID(USR0100) the ones from USR0100 to USR0199. MONMSG MSGID(ELC0000) catches them too, since it catches every message.
