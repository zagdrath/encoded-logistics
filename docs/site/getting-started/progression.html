Progression

The tech path read off the recipes, from vanilla materials to a full rack of servers, and what each new material unlocks.

Encoded Logistics has no research tree or unlock gates: what you can build depends only on what you can craft. The recipes fall into tiers, set by the four dies the Lithography Press makes and the three metals you mine for them. This page walks through those tiers in order and points to where each thing is documented.

1. Vanilla materials#

Everything starts from the Overworld's basics. Ferrite (iron and redstone), Copper Foil, Fiberglass and Solder Paste make the Circuit Substrate that nearly every device needs, and sand goes through Silica, Silica Blend and the Silicon Boule to Silicon Wafers. Your first network has the steps, and Fabrication materials the whole fabrication chain.

2. The press and the Logic Die#

The Lithography Press needs only iron, glass, Ferrite, redstone and a substrate, plus FE from another mod. Its first two photomasks, the Logic Photomask and the Storage Photomask, need nothing more, so the Logic Die and the 8K Storage Die are the first dies you make. See Lithography.

Logic Dies alone are enough for a lot:

  • A first network. The Network Controller (it also takes a diamond), Power Inlet, Network Cable, Drive Bay, Access Terminal, and 8K and 32K Storage Drives for items and fluids. Your first network builds one.
  • Early autocrafting with the Midrange line. The Midrange System, Expansion Cabinet, Card Punch, Card Reader, Line Printer, Disk Drive and Tape Drive need only Logic Dies, Ferrite and vanilla materials. You punch crafting recipes onto Punch Cards, read them onto an 8" Diskette, and the Midrange System crafts them itself, long before you have a Processor Die. A Midrange System is also its own network's controller, so it can stand in for a Network Controller. See The Midrange line.
  • The Server Rack and the Terminal Desk. The Server Rack itself is iron and Ferrite, and the Terminal Desk (which runs the Terminal OS) is built round an Access Terminal. A few rack devices are Logic Die tier too: the 2U Network Controller and the 24-Port L2 Switch.
  • Signals and displays. The Control Interface, Programmable Logic Controller and Display Panel. See Control and facility.
  • Cable tools and simple parts. Dense Network Cable, the Segment Isolator, the Cable Anchor and Cable Facade, the Threshold Sensor, the Collector Plane and Deployer Plane, and the Filter and Redstone Control Modules. See Networks.

3. Neodymium and tantalum: the Memory Die#

Next you mine. Neodymium Ore is common from y -32 up to y 48; Tantalum Ore lies deeper, below y -8, so you'll mostly find it as Deepslate Tantalum Ore. Both need an iron pickaxe. Smelt the raw metals into ingots. Heights and vein sizes are on Ores and metals.

  • Tantalum Capacitor: a tantalum ingot, Copper Foil and Solder Paste make two.
  • Doped Silicon: a Silicon Wafer and redstone. It's the wafer for the two higher dies.
  • The Memory Photomask (Doped Silicon in the centre) lets the press etch the Memory Die.

4. Gallium: the Processor Die#

Gallium is the deepest and rarest: Deepslate Gallium Ore only, below y -32. A gallium ingot in the Processor Photomask, and another as the press's additive with Doped Silicon, make the Processor Die. Many of the same recipes also want a Heatsink (copper and Ferrite).

Gallium also goes straight into Fiber Cable, the Optical Transceiver and the Radio Module, so it opens up long-distance and wireless networking as well as the top tier of devices:

5. Autocrafting#

With Processor Dies you can build the full autocrafting chain:

  1. A Schematic Encoder writes recipes onto Schematic Cards: crafting recipes, and processing recipes for machines, with fluids and gases. See Schematics.
  2. Fabricators craft the crafting schematics, and Gateways next to machines run the processing ones. See Fabricators and Gateways.
  3. A Scheduler (a Scheduler Core with Job Buffers and Thread Units) plans and runs jobs, or Compute and Memory Servers do it in a rack. See Schedulers.
  4. You ask for an item from any terminal and follow the job on Job Status. See Crafting jobs.

If you've been crafting on a Midrange System, its diskettes' recipes keep working alongside: they're network recipes like any other.

6. A full rack setup#

The last step is to move the network's core into Server Racks: a redundant pair of rack Network Controllers, a Firewall guarding who may do what, UPSes riding out power cuts, switches pooling lanes, servers running the jobs, NAS and SAN storage, and Tape Libraries archiving what you rarely use. Routers, Exchange Switches and optical lines then join separate networks together. Start at Server racks and Networking, and use the Terminal OS to watch and script all of it.
