The reference pages are for looking things up rather than reading through. They aren't written by hand: the site
generates them from the mod's own data (its registries, recipes, tags, config spec, language file and ELCL command
and message tables), so they match the version shown in the footer, {{version}}. For how things work and how to use
them, start from the guide sections instead; every entry here links back to the guide pages that cover it.

## Game content

| Page | What's in it |
|---|---|
| [Blocks and items](page:reference/items/index) | Every block and item, each with its own page: icon, description and tooltip, recipes, what it's used to make, tags, the device type it becomes on a network and the guide pages that cover it. |
| [Recipes](page:reference/recipes) | Every recipe in the mod, by machine: crafting, Lithography Press, smelting and blasting, stonecutting, Arcforge's Arc Crusher and the special recipes. |
| [Tags](page:reference/tags) | The mod's item and block tags and what's in them. |
| [Sounds](page:reference/sounds) | Every sound event, with its subtitle, for resource packs. |
| [Data components](page:reference/data-components) | The item data components the mod registers and what each one holds, for pack makers and add-on authors. |
