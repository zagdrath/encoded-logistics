ENCODED LOGISTICS - HANDOFF: MIDRANGE SYSTEM LINE (2 tiers, Expansion Cabinet, Keypunch, Card Reader, Line Printer,
Punch Card, 8" Diskette, Diskette Magazine)
=====================================================================================================================
An early-game autocrafting computer line before the Scheduler: Midrange System -> Integrated Midrange System -> Scheduler
-> Rack Scheduler -> Mainframe. Slow, craftable from Phase 1-2 materials. Matches the attached references (a 1980s
system unit with its extension cabinet; a later all-in-one system with an integrated console) in era, proportions and
details - unbranded and original (no logo, model number or wordmark). REPLACES the earlier Midrange System package
(never implemented): models, footprints and textures here supersede it.
Reviewed against repo HEAD 29bd97b. Paths are relative to the repo root; the zip mirrors them under src/.

=====================================================================================================
1. SCALE RULE, FOOTPRINTS, SHAPES
=====================================================================================================
Every model is at true real-world proportions on one scale: 1 model px = 6.25 cm, 16 px = 1 m = 1 block. Models are NOT
rounded up to whole blocks; each block is a multiblock footprint (master + dummies) containing the model. Models sit
flush to the BACK of the footprint (z = 16 with the front facing north / -z) and centred across its width.
  Block                       Model W x H x D (px)    Real size              Footprint (W x H x D blocks)
  midrange_system             18 x 16 x 12            1.13 x 1.00 x 0.75 m   2 x 1 x 1  (master x 0-16, dummy +x)
  expansion_cabinet           10 x 16 x 12            0.63 x 1.00 x 0.75 m   1 x 1 x 1
  integrated_midrange         28 x 20 x 12            1.75 x 1.25 x 0.75 m   2 x 2 x 1  (master lower; dummies +x, +y, +x+y)
  keypunch                    16 x 18 x 12            1.00 x 1.12 x 0.75 m   1 x 2 x 1  (desk 0.75 m, card unit to 1.06 m)
  card_reader                 10 x 16 x 10            0.63 x 1.00 x 0.63 m   1 x 1 x 1
  line_printer                20 x 17 x 12 (+ paper to 21)  1.25 x 1.06 x 0.75 m   2 x 2 x 1
  (Peripheral sizes are typical proportions for period equipment of each kind: a desk keypunch station with its raised
   card-path unit, a free-standing box card reader, a heavy cabinet line printer.)
Every model fits the block model limits (-16..32), so NO block entity renderer is needed; all are static models on the
master (multipart / variants), the dummies use empty.json. Footprint blocks lie along the model's local +x / +y and
rotate with facing (place the dummies at master + localX/localY rotated by the facing, as the Server Rack does).
Collision AND selection shapes follow the model, per footprint block: shapes/collision_shapes.json lists, for every
block of every footprint, the boxes (in that block's local px, facing north) clipped from the model's solid parts; rotate
them by facing (VoxelShape per facing, cached). Rotated plates count as their unrotated boxes.
Midrange System shapes (expansion = none / pos / neg):
      block 0,0,0: [7, 1, 4, 16, 13, 16]; [7.5, 0, 4.5, 16, 1, 15.5]; [14, 13, 5, 16, 13.5, 16]; [7, 13, 7.4, 14, 16, 16]; [7, 13, 6, 14, 13.6, 7.4]
      block 1,0,0: [0, 1, 4, 9, 13, 16]; [0, 0, 4.5, 8.5, 1, 15.5]; [0, 13, 6.4, 9, 16, 16]; [0, 13, 5, 9, 13.6, 6.4]
  (other blocks: see the JSON.)

2. MIDRANGE SYSTEM (tier 1) - midrange_system, 1 lane
=====================================================================================================
Model: broad waist-high cream cabinet (body 18 x 12 x 12 on a 1 px recessed plinth); on top, the diskette housing at
the TOP LEFT (slanted face: smoked window, the 8" slot with its latch - two slots when an Expansion Cabinet is
attached), a low deck, and the operator housing at the TOP RIGHT (slanted face: a dark strip with power / attention /
activity / I/O lamps, a 2-character status display, function buttons, keyswitch). Front: top seam, a service-cover seam,
louvred vents low; left side panel: front-top vents, a cover seam and the red emergency power-off switch; rear: I/O panel
with terminal connectors and vents.
BlockState: facing, part (master|dummy), state (off|ipl|run|busy|attn), expansion (none|pos|neg).
  expansion moves the model flush to the side the cabinet is on (none: centred x 7-25; pos: 14-32; neg: 0-18) so the
  pair reads as one machine 28 px (1.75 m) wide. Shapes follow (JSON).
States (models/block/midrange_system/midrange_system_<exp>_<state>.json, emissive overlay on the operator plate):
  off - no overlay; ipl - panel_ipl.png 8 frames x 5 ticks (codes C1 C3 C6 C9 CA CC -- A6, lamps flicker; IPL 100 ticks
  [config], then run); run - steady A6 + power lamp; busy - activity lamp blinks, display counts (10 x 4 ticks);
  attn - attention lamp + error code E2 blinking (2 x 8). Error codes: E1 no diskette, E2 missing ingredients (held
  job), E3 output full, E4 no power, E9 network offline.
Behaviour: holds ONE 8" Diskette (job library, up to 8 recipes); crafts crafting-table recipes from it itself: 1 thread,
  max job 64 (open question 1), slow; a Scheduler choice on the Craft Plan screen ("Midrange <name>"); dispatches steps
  to the network's Fabricators / Gateways when present; ELCL batch job host for 1 job; 1 lane; network power [config
  4 FE/t + 20 FE per craft]. Default device name MIDRANGEnn.
Control panel GUI (right-click the cabinet; green-screen, CRT grid): status code, threads / max job / batch jobs, the
  diskette slot(s) with library names and recipe counts, current job + progress, job queue, IPL / Hold queue / Release
  (F7 / F10 / F11). previews/gui_midrange_panel(.png, _expansion.png).
Sounds: sounds/block/midrange/midrange_fan (loop while on), diskette_latch (insert/remove), drive_seek (ipl / busy).

=====================================================================================================
3. EXPANSION CABINET - expansion_cabinet (upgrade for tier 1)
=====================================================================================================
Model: same styling, plain front with low vents, a cap matching the Midrange housings, a small green lamp (lit when
attached and the system is on). BlockState: facing, attached (none|pos|neg = the side its Midrange System is on; the
model sits flush toward it), lit.
Attachment rule: it attaches when placed DIRECTLY beside a Midrange System's footprint along that system's width
(the block left of the master or right of the dummy), with the SAME facing and the same y and depth row. One cabinet per
system; anywhere else (or a second one) it does nothing (attached = none, model centred). Placing or breaking it updates
the system's expansion state and both models.
When attached: +1 thread (2), +1 diskette slot (the second slot shows on the system's diskette housing and in its GUI),
max job 128, +1 ELCL batch job (2). No lane, no extra power beyond [config 1 FE/t].

=====================================================================================================
4. INTEGRATED MIDRANGE SYSTEM (tier 2) - integrated_midrange, 1 lane
=====================================================================================================
Model: a wide two-panel cabinet (vent bands across the top of both front panels), a diskette MAGAZINE drive unit on the
top LEFT (smoked window showing the magazine's diskettes, latch), and the integrated console on the top RIGHT: a hood
with a slanted dark fascia - recessed display, lamp matrix, two rotary selectors, buttons, a 3-digit status display - and
a recessed keyboard tray in front. Visibly a newer generation (wider, two-panel, console built in).
BlockState: facing, part (master|dummy x3), state (off|ipl|run|busy|attn), console (off|boot|on).
  console boot / on show the Terminal Desk's own emissive screen textures (block/terminal_desk/crt_screen_boot / _on) in
  the fascia's display; on = a session is signed on at it. State overlays: fascia_<state>.png (56 x 24 frames).
Behaviour: holds a Diskette Magazine (4 diskettes = 32 recipes); 4 threads; max job 512; ELCL batch job host for 4 jobs;
  1 lane; network power [config 8 FE/t + 20 FE per craft]; no Expansion Cabinet. Default name MIDRANGEnn too.
Two click zones: the console (hood, fascia, keyboard tray - their boxes in the shapes) opens the Terminal OS directly
  (exactly like a Terminal Desk: same session, sign-on, screens); anywhere else on the cabinet opens the control panel
  (as tier 1 with the magazine view: the magazine slot + its 4 diskettes, current jobs list). previews/gui_integrated_panel.

=====================================================================================================
5. PERIPHERALS (each 1 block of logic; footprints above)
=====================================================================================================
Connection: works when ADJACENT to any block of a Midrange System, Expansion Cabinet or Integrated Midrange System, or
cabled to the same network (open question 3: lanes when cabled). Uses the nearest / first Midrange on the network.
  keypunch - desk with a pedestal (right) and kneehole (left), keyboard on the desk, raised card-path unit at the back,
    card hopper (top right, tilted), punch station, stacker (top left). Encodes ONE crafting recipe onto a blank Punch
    Card. GUI: 3x3 grid, output preview, blank-card slot, punched-card slot, PUNCH (F6). Active: card_feed.png (8 x 2
    ticks) runs along the card bed; sound keypunch_clatter.
  card_reader - box reader: input hopper (right), output stacker (left), feed track between, operator lamps. Reads up to
    8 cards onto an 8" Diskette (8 recipes per diskette; duplicates replace). GUI: 8-card hopper, diskette slot, READ (F6).
    Active: track.png (6 x 1 tick) + lamps; sound card_reader_whirr.
  line_printer - stand cabinet, printer unit with the control strip, smoked lid raised, tractor ends, fan-fold paper
    rising out of the top into the rear wire basket. Prints Written Books: network inventory listing, job log, device
    list, or an ELCL spooled file (report 4, File *LAST or a name). Consumes paper (open question 5). Active:
    paper_printing.png scrolls (8 x 2), panel_glow.png; sound line_printer_chatter.
  Peripheral GUIs: previews/gui_keypunch, gui_card_reader, gui_line_printer (green-screen, slots as phosphor frames).

always returns ELC0301 ("no job host"), ScreenQueries.jobs shows hosts 0/0, StubSpoolService.print always ELC1301
